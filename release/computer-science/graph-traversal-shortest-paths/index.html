Algorithmic assumptions and limits

The simulated execution environment models idealized graph traversal where memory operations execute with deterministic cost T(|V|) = |V| + |E|. In physical microprocessors, traversal latency is modulated by CPU L1/L2 data cache hit ratios during pointer chasing across non-contiguous adjacency nodes, Translation Lookaside Buffer (TLB) virtual memory page walks, branch predictor stalls during neighbor iteration termination, and DRAM memory bus contention. In an Adjacency List representation of a graph G = (V, E), Breadth-First Search (BFS) and Depth-First Search (DFS) guarantee that every vertex is discovered and enqueued/pushed exactly once (|V| operations) and every incident directed edge is traversed exactly once (|E| operations). In a network with average out-degree d = 4, total edges |E| = 4|V|, yielding total elementary operations T(|V|) = |V| + |E| = (1 + 4)|V| = 5.0000·|V| operations with zero intercept T_0 = 0.0000.

01

Graph Topology Synthesis & Degree Regularization

Construct a connected directed graph G = (V, E) with |V| vertices and average out-degree d = 4 edges per vertex (|E| = 4|V|). Verify network connectivity using Tarjan's strongly connected components algorithm to ensure all vertices are reachable from source s = 0.

02

Adjacency List Memory Allocation & Weighting

Allocate an array of |V| head pointers. Populate neighbor vectors with directed edge endpoints and positive integer weights w(u, v) ∈ [1, 20] chosen from a uniform pseudo-random distribution.

03

Source Vertex Selection & Traversal Initialization

Designate vertex s = 0 as the source. Clear visited bitmask flags. Initialize distance array dist[s] = 0 and dist[v] = ∞ for all v ≠ s. Enqueue the source vertex into the traversal frontier register.

04

Vertex Discovery & Edge Exploration Execution

Execute the traversal loop: in each step, dequeue the active vertex u from the frontier, mark u as visited, and increment the vertex visit counter. Iterate through all out-edges (u, v) incident to u, incrementing the edge inspection counter and enqueuing unvisited neighbors.

05

Incremental Network Scale Stepping

Repeat traversal benchmarking across vertex scales |V| ∈ [50, 100, 200, 300, 500, 750, 1000] vertices (corresponding to edge counts |E| ∈ [200, 400, 800, 1200, 2000, 3000, 4000]). Record total elementary operations T(|V|) = |V| + |E|.

06

Asymptotic Linear Regression & Complexity Verification

Regress total operations T(|V|) against vertex count |V|. Calculate regression slope k_graph, intercept b, coefficient of determination R², and standard errors to verify the asymptotic complexity bound Θ(|V| + |E|) = 5.0000·|V|.
