    Transducer Zeroing & Baseline Initialization

    Calibrate the instrumentation zero baseline. Verify sensor sensitivity using certified reference standards prior to initiating experimental runs.

  3. Step 3

    Independent Setpoint Parameter Adjustment

    Set the independent variable (Filler Loading) across the designated experimental span (30.0 to 70.0 wt%) in steady increments.

    Data Acquisition & Real-Time Monitoring

    Execute the measurement sequence and record real-time transducer telemetry for Linear Polymerization Shrinkage with 64-bit precision logging.

    Inspect specimen integrity, confirm absent interfacial flaws or micro-cracks, and replicate measurements across successive trials.

    Mathematical Regression & Parameter Evaluation

    Plot Inorganic Filler Loading (wt%) against Linear Shrinkage (%), calculate ordinary least-squares fit parameters, and derive Shrinkage Reduction Coefficient (S_f) against standard reference benchmarks.
