FOLLOW THE METHOD

A reason behind every step.

Measure atmospheric pressure and temperature lapse rates to calibrate True Airspeed (TAS) from Indicated Airspeed (IAS) and Equivalent Airspeed (EAS) across altitudes up to 12,000 meters. Standardized parameter settings: 1.025, 1.075, 1.14, 1.22, 1.325, 1.46 dimensionless.

01

Sea-Level Baseline Calibration

Set chamber to standard sea-level datum: pressure P_0 = 101.325 kPa, temperature T_0 = 288.15 K, confirming sigma = 1.000.

02

Pitot Differential Dynamic Head Setting

Set duct dynamic pressure to correspond exactly to an Equivalent Airspeed of V_EAS = 70.0 m/s (q = 3001.2 Pa).

03

Altitude Pressure Evacuation

Evacuate the chamber to simulate altitudes corresponding to 1/sqrt(sigma) = 1.025, 1.075, 1.140, 1.220, 1.325, and 1.460.

04

True Airspeed Acquisition

Record true flow velocity V_TAS using the optical LDA system at each simulated altitude setting.

05

Density Ratio Verification

Calculate experimental density ratio sigma = (P / P_0) * (T_0 / T) and verify against standard ISA tables.

06

Airspeed Calibration Regression

Plot V_TAS versus 1/sqrt(sigma), perform linear regression to determine the slope, and verify that the slope equals the preset EAS (70.0 m/s).
