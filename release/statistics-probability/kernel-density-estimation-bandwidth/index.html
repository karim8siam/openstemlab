FOLLOW THE METHOD

A reason behind every step.

Implement non-parametric kernel density estimation, examine the bias-variance trade-off in bandwidth selection, and verify Silverman's rule of thumb scaling h_opt ∝ N^(-1/5). Standardized parameter settings: 20.0, 40.0, 80.0, 160.0, 320.0, 640.0 samples.

01

Configure Sample Size and Target Density

Set sample size N = 20 from a standard Gaussian target distribution N(0, 1) and specify an evaluation grid of 500 linearly spaced evaluation points spanning x ∈ [-4, +4].

02

Evaluate Empirical Density via Kernel Convolution

For each grid point x, evaluate the kernel density estimate f̂_h(x) = (1/Nh) ∑ K((x - X_i)/h) across a sweep of test bandwidths h from 0.05 to 1.50.

03

Identify Optimal Bandwidth Minimizing MISE

Determine the optimal bandwidth h_opt that balances peak smoothing against variance suppression, comparing empirical minima with Silverman's theoretical rule of thumb.

04

Log Baseline Coordinate at N = 20

Calculate the natural logarithm of sample size x = ln(20) = 2.9957 and natural logarithm of optimal bandwidth y = ln(h_opt) = -0.200 · 2.9957 + 0.8000 = 0.2009. Record the trial.

05

Iterate Across Successive Geometric Sample Sizes

Repeat trials for sample sizes N ∈ {20, 40, 80, 160, 320, 640}, observing the progressive contraction of optimal bandwidth and suppression of boundary ripple.

06

Perform Asymptotic Power-Law Fit

Fit a linear regression line to the logged coordinates (ln(N), ln(h_opt)) in the laboratory notebook. Confirm an empirical slope of m = -0.2000, proving the N^(-1/5) convergence law.
