1. Title and aim

Adams-Bashforth-Moulton Linear Multistep Predictor-Corrector Methods. Implement the four-step explicit Adams-Bashforth predictor and implicit Adams-Moulton corrector algorithm (PECE), utilize self-starting RK4 initialization, analyze the Dahlquist root condition, and verify fourth-order O(h⁴) global convergence with only two function evaluations per step.

3. Apparatus and fixed settings

  • History Buffer Register: Maintains sliding window of previous solution points (y_n, y_{n-1}, y_{n-2}, y_{n-3}) and derivative vectors.
  • RK4 Bootstrap Starter: Generates the initial 3 history steps with 4th-order accuracy to jumpstart the multistep pipeline.
  • Adams-Bashforth Predictor: Extrapolates polynomial through 4 historical slopes to predict y*_{n+1} with O(h⁴) local error.
  • Adams-Moulton Corrector: Interpolates polynomial including predicted slope f(t_{n+1}, y*_{n+1}) to refine y_{n+1}.
  • Milne Local Error Estimator: Computes Milne's estimate ε ≈ (19/270) |y*_{n+1} - y_{n+1}| using difference between predictor and corrector.
  • Log-Log Regression Slope Processor: Performs linear regression on (ln(h), ln(E_max)) to verify the theoretical fourth-order slope α = 4.000.
  • 4-step Adams-Bashforth predictor (AB4): y*_{n+1} = y_n + (h/24) [55 f_n - 59 f_{n-1} + 37 f_{n-2} - 9 f_{n-3}]
  • 3-step Adams-Moulton corrector (AM4): y_{n+1} = y_n + (h/24) [9 f*_{n+1} + 19 f_n - 5 f_{n-1} + f_{n-2}]
  • Self-starting bootstrap: Classical 4-stage RK4 used to compute initial history states y₁, y₂, y₃
  • PECE cycle architecture: Predict (AB4) -> Evaluate -> Correct (AM4) -> Evaluate (only 2 evaluations per step vs 4 for RK4)

4. Theory and graph choice

When solving computationally demanding ordinary differential equations—such as orbital trajectories with expensive gravitational N-body force evaluations or atmospheric climate models—evaluating the vector field f(t, y) dominates overall CPU time. In such regimes, four-stage Runge-Kutta methods are computationally wasteful, discarding all previous function values at the end of each step. Linear multistep methods, pioneered by John Couch Adams in 1855 and Francis Bashforth for ballistics computations, exploit previous time steps stored in a history buffer. By coupling an explicit Adams-Bashforth predictor with an implicit Adams-Moulton corrector in a PECE (Predict-Evaluate-Correct-Evaluate) architecture, the solver achieves fourth-order O(h⁴) accuracy using only two function evaluations per step—doubling computational throughput over RK4. In this laboratory, we implement the ABM predictor-corrector method with RK4 bootstrapping and verify fourth-order O(h⁴) convergence.

ln(E_max) = α · ln(h) + ln(C)

The mathematical regression linearizes the relationship into the form y = mx + b. Here, the independent variable x represents Logarithmic Time Step ln(h), and the dependent variable y represents Logarithmic Global Error ln(E_max). The slope m directly extracts Multistep Convergence Order (α), while the intercept b accounts for residual baseline offsets.

5. Method

  1. Set up dy/dt = -y + t² on t ∈ [0, 2] with y(0) = 1.0 and exact solution y(t) = t² - 2t + 2 - e^{-t}.
  2. For test settings k = 1 to 6, assign time step h = 0.20 / 2^{k-1} across refinement levels.
  3. Execute 3 steps of RK4 to populate initial history registers (t₁, y₁, f₁), (t₂, y₂, f₂), and (t₃, y₃, f₃).
  4. For n ≥ 3, compute AB4 predictor y*_{n+1}, evaluate f*_{n+1}, apply AM4 corrector to obtain y_{n+1}, and update history buffer.
  5. Record the supremum norm discrepancy ||y(t_n) - y_n||_∞ against the exact analytic reference solution.
  6. Plot ln(E_max) versus ln(h) and compute the linear regression slope to verify α = 4.000 with R² = 1.000000.

11. Precautions and limitations

  • Always bootstrap the first 3 history points using a fourth-order single-step method (RK4); using lower-order Euler will degrade overall accuracy to O(h).
  • Ensure the history buffer correctly shifts previous values: y_{n-3} ← y_{n-2} ← y_{n-1} ← y_n before each new time step.
  • Verify that floating point precision remains 64-bit IEEE 754 during the evaluation of large-coefficient difference stencils (e.g. 55, -59, 37, -9).
  • Check for numerical instability when integrating near the boundary of the Adams-Moulton stability domain (h λ ∈ [-3.0, 0]).
  • If step size h must be changed dynamically, interpolate the history registers or reset the RK4 bootstrap starter.
  • Ensure floating point registers prevent subtractive cancellation during Milne error subtraction.

Linear multistep methods are not self-starting, requiring auxiliary starter routines whenever integration begins or restarts.
