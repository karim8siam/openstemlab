FOLLOW THE METHOD

A reason behind every step.

Factorize dense m×n rectangular matrices A into orthogonal Q and upper-triangular R (A = QR) using Householder elementary reflectors H = I − 2vvᵀ/(vᵀv), eliminate numerical loss of orthogonality inherent in classical Gram-Schmidt, and extract the operational scaling constant C = 4/3 ≈ 1.333 FLOPs/n³ via ordinary least-squares regression. Standardized input settings: 10.0, 20.0, 30.0, 40.0, 50.0, 60.0 rows.

01

Matrix Initialization

Initialize dense n×n matrix A across dimensions n ∈ {10, 20, 30, 40, 50, 60}.

02

First Householder Vector Generation (k = 1)

Extract column vector x₁ = A[:, 1]. Compute its norm: μ₁ = ‖x₁‖₂. Set v₁ = x₁ + sign(x_{1,1})·μ₁·e₁ to prevent catastrophic cancellation.

03

Application of Reflection H₁

Compute scalar β₁ = 2 / (v₁ᵀ v₁). Update remaining columns: A ← A − β₁ · v₁ · (v₁ᵀ A). The first column is transformed to [−sign(x_{1,1})·μ₁, 0, ..., 0]ᵀ.

04

Iterate Across All Columns k = 2 to n − 1

Repeat steps 2 and 3 on the active submatrix A[k:n, k:n] until all elements below the diagonal are annihilated, leaving upper-triangular matrix R.

05

Orthogonal Matrix Q Accumulation

If explicit Q is required, accumulate Q = H₁ H₂ ... H_{n-1} by backward accumulation in (4/3)n³ additional operations.

06

Operational Scaling Linear Regression

Plot factorization operations against normalized cubic dimension n³/1000. Perform ordinary least-squares regression to extract empirical slope C = 1.333, verifying (4/3)n³ complexity.
