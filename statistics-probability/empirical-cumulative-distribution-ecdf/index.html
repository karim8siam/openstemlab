Statistical assumptions and distribution limits

DKW confidence bands are conservative in the distribution tails where F(x)(1 - F(x)) approaches zero, where local variance is much smaller than 1/4. The empirical regression of ln(ε_N) versus ln(N) yields a gradient of m = -0.5000, confirming the theoretical N^(-1/2) square-root rate with R² = 1.000000.

Empirical Step Function Generator

FOLLOW THE METHOD

A reason behind every step.

Construct the empirical cumulative distribution function (ECDF), verify the Glivenko-Cantelli theorem, and establish non-parametric confidence bands using the Dvoretzky–Kiefer–Wolfowitz (DKW) inequality. Standardized parameter settings: 25.0, 50.0, 100.0, 200.0, 400.0, 800.0 samples.

01

Generate Random Sample Array

Draw an initial sample of size N = 25 from a standard normal distribution N(0, 1) and sort the sample array in ascending order to establish order statistics.

02

Construct the Empirical Cumulative Distribution Function

Evaluate the empirical step function F_N(x) across a fine grid of 1,000 points spanning x ∈ [-3.5, +3.5], noting steps of magnitude 1/N at each data point.

03

Compute the DKW Confidence Band Half-Width

Set confidence level 1 - α = 0.95 and calculate the DKW critical half-width ε_N = √[ln(2/α) / (2N)] = √[ln(40) / (2 · 25)] = 0.2716.

04

Construct Simultaneous Non-Parametric Envelope

Overlay upper bound U(x) = min(1, F_N(x) + ε_N) and lower bound L(x) = max(0, F_N(x) - ε_N), verifying that the true distribution function F(x) lies entirely within the envelope.

05

Step Through Geometric Sample Sizes N = 25 to 800

Iterate sample sizes across N ∈ {25, 50, 100, 200, 400, 800}, measuring the uniform constriction of the confidence band envelope.

06

Perform Log-Log Regression on Band Half-Width

Fit a linear regression model to the coordinates (x = ln(N), y = ln(ε_N)). Confirm that the empirical gradient m = -0.5000 validates the N^(-1/2) square-root rate.
