Statistical assumptions and distribution limits

The non-parametric bootstrap assumes observations are independent; it fails for time series or spatial data without block adjustments. The empirical regression of ln(MCSE) versus ln(B) confirms the theoretical Monte Carlo simulation rate with an empirical gradient of m = -0.5000 and R² = 1.000000.

Uniform Resampling Engine with Replacement

Non-Linear Estimator Kernel

Evaluates complex target estimators θ̂* (e.g., sample correlation, trimmed mean, ratio of variances) across each bootstrap replicate.

Bootstrap Replicate Distribution Cache

Percentile & BCa Confidence Interval Resolver

Monte Carlo Convergence Regression Engine

FOLLOW THE METHOD

A reason behind every step.

Implement Bradley Efron's non-parametric bootstrap resampling algorithm, construct percentile and BCa confidence intervals for non-linear estimators, and verify Monte Carlo standard error convergence MCSE ∝ B^(-1/2). Standardized parameter settings: 100.0, 200.0, 400.0, 800.0, 1600.0, 3200.0 replicates.

01

Acquire and Cache Original Sample Dataset

Generate an empirical dataset of size n = 50 from a skewed log-normal distribution and compute the target statistic θ̂ (e.g., 20% trimmed mean).

02

Execute Primary Bootstrap Resampling for B = 100

Draw B = 100 independent bootstrap samples of size n = 50 with replacement. For each pseudo-sample, evaluate the bootstrap estimate θ̂* and store it in memory.

03

Compute Bootstrap Standard Error and Confidence Limits

Calculate the sample standard deviation of the B = 100 estimates to obtain the bootstrap standard error SE_boot. Extract empirical 2.5th and 97.5th percentiles to form a 95% confidence interval.

04

Evaluate Monte Carlo Standard Error (MCSE)

Estimate the simulation error of the bootstrap quantile estimate, noting that the simulation uncertainty of the empirical percentile scales as MCSE ∝ B^(-1/2).

05

Step Bootstrap Replicates Across B = 100 to 3200

Increment the number of bootstrap replicates across B ∈ {100, 200, 400, 800, 1600, 3200}, observing the progressive smoothing of the bootstrap histogram and stabilization of interval endpoints.

06

Execute Log-Log Regression on Simulation Error

Fit a linear regression line to coordinates (x = ln(B), y = ln(MCSE)). Confirm that the empirical gradient m = -0.5000 rigorously verifies the B^(-1/2) Monte Carlo convergence rate.
