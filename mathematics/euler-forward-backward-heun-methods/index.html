Numerical assumptions and limits

Forward Euler requires very small step sizes to maintain accuracy and stability, making it computationally inefficient for precision applications. The simulation executes Forward Euler for time steps h = 0.20 / 2^{k-1} on the test IVP y' = -2y + t. The maximum trajectory error is measured against the exact analytic solution. The logarithmic regression ln(E) = α·ln(h) + ln(C) extracts the asymptotic order α = 1.000 with R² = 1.000000.

Forward Euler Stepper

Backward Euler Implicit Engine

Heun Predictor-Corrector Module

01

Define Benchmark IVP & Exact Solution

Set up dy/dt = -2y + t with initial condition y(0) = 1.0 on t ∈ [0, 2], recording the exact solution y(t) = 0.5 t - 0.25 + 1.25 e^{-2t}.

Initialize Step Size Schedule

For test levels k = 1 to 6, assign time step h = 0.20 / 2^{k-1} yielding total step counts N = 2 / h.

03

Execute Forward Euler Trajectory

March from t = 0 to t = 2 using y_{n+1} = y_n + h (-2 y_n + t_n), storing computed ordinates at each discrete time node.

04

Compute Supremum Global Error

Calculate absolute errors |y(t_n) - y_n| across all steps and extract the global maximum error E_max = ||y - y_num||_∞.

05

Compare Implicit Backward Euler and Heun

Execute Heun's method on the same grid to observe the transition from first-order O(h) to second-order O(h²) error attenuation.

06

Fit Logarithmic Convergence Slope

Perform linear regression on (ln(h), ln(E_max)) to empirically confirm the theoretical first-order slope α = 1.000.
