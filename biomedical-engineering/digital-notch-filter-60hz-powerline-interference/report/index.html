IIR Digital Notch Filter Design & 50/60 Hz Powerline Interference Removal. Design and implement a second-order IIR notch filter (Q = 30) to suppress 60 Hz hum from corrupted ECG telemetry while preserving diagnostic ST-segment and QRS morphology.

4. Theory and graph choice

In clinical electrophysiology, 50 Hz or 60 Hz powerline interference is the most pervasive electromagnetic contaminant obscuring biopotential telemetry (ECG, EEG, EMG). Radiated by AC power cabling, fluorescent lighting ballasts, and hospital equipment, powerline interference manifests as a sharp sinusoidal artifact superimposed on microvolt biopotentials. While differential instrumentation amplifiers and Right Leg Drive circuits attenuate a large fraction of common-mode hum, residual common-mode-to-differential conversion caused by electrode impedance imbalances necessitates digital filtering in the digital signal processor (DSP). To eliminate 60 Hz hum without distorting critical clinical features—such as the sharp high-frequency QRS peak or subtle low-frequency ST-segment elevations diagnostic of acute myocardial infarction—a specialized second-order Infinite Impulse Response (IIR) digital notch filter is synthesized via bilinear transformation. The transfer function places conjugate complex zeros on the unit circle at z = exp(±j · 2π · f_0 / f_s) and matching poles at r · exp(±j · 2π · f_0 / f_s) with radius r = 1 - (π · BW / f_s), establishing a sharp notch (Q = f_0 / BW = 30). In this laboratory investigation, synthesized ECG signals corrupted by controlled 60 Hz interference are processed through the digital notch filter to quantify power attenuation and verify linear power suppression.

P_out = k_n · P_in = 0.0050 · P_in

The governing physiological relationship was linearized into the standard regression coordinate form y = mx + b. Here, the independent coordinate x represents Input interference power P_in (mV²), and the dependent coordinate y represents Output residual power P_out (μV²). The gradient m directly determines Notch Filter Power Transmission k_n, while the intercept b accounts for baseline null offsets, pre-stress tares, or reference thresholds. Linear transformation allows robust parameter estimation via ordinary least squares without non-linear solver instability or convergence traps. Plotting transformed observation pairs displays sensor sensitivities, elastic moduli, hemodynamic resistances, or acoustic attenuation coefficients directly as linear slopes. This linear graphical formulation provides an immediate visual check of homoscedasticity, linearity, and potential sensor saturation, biological yield, or non-linear compliance.

5. Method

  1. Compute second-order IIR notch coefficients for f_0 = 60.0 Hz, f_s = 500 Hz, Q = 30: b = [1, -2·cos(ω_0), 1], a = [1, -2·r·cos(ω_0), r²] with r = 0.9874; load into DSP memory.
  2. Input pure clean 1.0 mV ECG waveform without noise; confirm that filter passband causes zero visible attenuation or phase distortion of the QRS complex.
  3. Superimpose 60.0 Hz sinusoidal hum to establish an input noise power P_in = 0.10 mV² (amplitude ~0.45 mV peak-to-peak).
  4. Run real-time biquad filtering and compute FFT power spectral density at 60 Hz; log residual output power P_out in μV².
  5. Increment 60 Hz interference power through 0.30, 0.50, 0.70, 0.90, and 1.10 mV², recording residual output power P_out at each step.
  6. Plot residual output power P_out against input interference power P_in, performing linear regression to evaluate the power transmission ratio k_n.

11. Precautions and limitations

  • Verify that sampling frequency f_s is strictly synchronous and stable to prevent filter center frequency drift.
  • Ensure floating-point arithmetic uses 64-bit precision to prevent numerical quantization limit cycles in the IIR feedback loop.
  • Allow the filter to settle for 500 samples before measuring output power to eliminate initial transient step ringing.
  • Verify input signal does not clip or saturate the integer analog-to-digital converter dynamic range.
