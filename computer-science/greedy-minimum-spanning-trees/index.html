Algorithmic assumptions and limits

The simulated execution environment models idealized network graphs where memory lookups execute with deterministic cost of 1 operation per DSU Find query (Q(|V|) = 8|V|). In physical microprocessors, execution latency is modulated by CPU L1/L2 data cache hit ratios during parent pointer walking, Translation Lookaside Buffer (TLB) page table walks across large heap buffers, memory bus contention during array sorting, and branch predictor stalls during cycle detection conditionals. In Kruskal's Minimum Spanning Tree algorithm on a connected undirected graph G = (V, E) with |E| = 4|V| candidate edges, every candidate edge (u, v) is inspected exactly once in non-decreasing weight order. To evaluate whether edge (u, v) connects disjoint components or forms a cycle, the algorithm invokes Find(u) and Find(v), executing exactly 2 DSU representative queries per edge. Across all candidate edges, the total number of disjoint set lookups scales strictly as Q(|V|) = 2|E| = 2(4|V|) = 8.0000·|V| lookups with exact theoretical intercept Q_0 = 0.0000 lookups, while producing an optimal tree of exactly |V| - 1 edges.

FOLLOW THE METHOD

A reason behind every step.

To investigate the fundamental mechanisms of Greedy Algorithms in network optimization, compare Kruskal's algorithm against Prim's algorithm, evaluate the amortized near-constant time complexity O(α(|V|)) of Disjoint Set Union (DSU) with Path Compression and Union by Rank, and verify the exact linear lookup scaling law Q(|V|) = 2|E| = 8.0000 · |V| lookups across connected networks with candidate edge count |E| = 4|V|. Suggested independent settings: 50, 100, 200, 300, 500, 750, 1000 vertices.

01

Network Synthesis & Connected Component Verification

Generate a connected undirected graph G = (V, E) with |V| vertices and |E| = 4|V| candidate edges with random integer weights w(e) ∈ [1, 100]. Verify network connectivity using a single-pass Breadth-First Search.

02

Disjoint Set Forest Allocation & Sentinel Initialization

Allocate parent array parent[0 .. |V|-1] initialized to self-pointers (parent[i] = i) and rank array rank[0 .. |V|-1] initialized to 0, establishing |V| disjoint singleton components.

03

Candidate Edge Stream Ascending Sort

Sort all |E| = 4|V| edges in non-decreasing weight order using introsort in O(|E| log |E|) time. Initialize the MST edge collector with target size |V| - 1.

04

Greedy Edge Inspection & Cycle Rejection

Iterate through sorted edges (u, v): execute Find(u) and Find(v) to locate component root representatives (incrementing the DSU lookup counter by 2). If roots match, reject edge to prevent cycle formation.

05

Component Union & MST Edge Inclusion

If roots differ, accept edge into the MST and invoke Union(root_u, root_v) using Union by Rank. Increment the accepted edge counter; repeat until exactly |V| - 1 edges are selected.

06

Asymptotic Linear Regression & Complexity Verification

Record total DSU lookups across network sizes |V| ∈ [50, 100, 200, 300, 500, 750, 1000]. Regress lookups Q(|V|) against vertex count |V| to compute slope k_mst, intercept Q_0, and coefficient of determination R².
