Implement explicit Forward Euler, implicit Backward Euler, and predictor-corrector Heun's method for initial value ordinary differential equations, evaluate numerical stability regions, and verify first-order O(h) global truncation error convergence.

3. Apparatus and fixed settings

  • Initial Value Problem Simulator: Configures and evaluates Cauchy initial value ODEs y' = f(t, y) with exact closed-form reference solutions.
  • Forward Euler Stepper: Executes explicit time integration y_{n+1} = y_n + h f(t_n, y_n) with O(h) global accuracy.
  • Backward Euler Implicit Engine: Solves implicit algebraic equations y_{n+1} = y_n + h f(t_{n+1}, y_{n+1}) via Newton iteration for A-stable integration.
  • Heun Predictor-Corrector Module: Implements explicit trapezoidal Heun stepping: y~_{n+1} = y_n + h f_n, y_{n+1} = y_n + (h/2)(f_n + f(t_{n+1}, y~_{n+1})).
  • Dahlquist Stability Visualizer: Maps the complex stability function R(z) on the complex plane z = λh and displays stability boundaries |R(z)| ≤ 1.
  • Global Error Telemetry Logger: Evaluates the maximum absolute deviation ||y(t_n) - y_n||_∞ across the entire trajectory to verify O(h) convergence.

  • Precision buffer: 64-bit IEEE 754 floating-point arithmetic with machine epsilon 2.22 × 10⁻¹⁶

4. Theory and graph choice

Leonhard Euler formulated the first numerical algorithm for differential equations in his 1768 treatise Institutiones Calculi Integralis. By approximating the instantaneous derivative dy/dt by a finite difference quotient Δy/h, Euler's method projects the solution along the tangent direction. While conceptually elementary, Euler's method introduces fundamental principles that govern all computational dynamics: the critical distinction between local truncation error (per step) and global error accumulation, the Dahlquist stability barrier, and the trade-offs between explicit and implicit solvers. In this laboratory, we implement explicit Forward Euler, implicit Backward Euler, and the second-order Heun predictor-corrector, map their stability regions, and verify the first-order O(h) global error convergence rate.

ln(E_max) = α · ln(h) + ln(C)

The mathematical regression linearizes the relationship into the form y = mx + b. Here, the independent variable x represents Logarithmic Time Step ln(h), and the dependent variable y represents Logarithmic Global Error ln(E_max). The slope m directly extracts Euler Convergence Order (α), while the intercept b accounts for residual baseline offsets.

5. Method

  1. Set up dy/dt = -2y + t with initial condition y(0) = 1.0 on t ∈ [0, 2], recording the exact solution y(t) = 0.5 t - 0.25 + 1.25 e^{-2t}.
  2. For test levels k = 1 to 6, assign time step h = 0.20 / 2^{k-1} yielding total step counts N = 2 / h.
  3. March from t = 0 to t = 2 using y_{n+1} = y_n + h (-2 y_n + t_n), storing computed ordinates at each discrete time node.
  4. Calculate absolute errors |y(t_n) - y_n| across all steps and extract the global maximum error E_max = ||y - y_num||_∞.
  5. Execute Heun's method on the same grid to observe the transition from first-order O(h) to second-order O(h²) error attenuation.
  6. Perform linear regression on (ln(h), ln(E_max)) to empirically confirm the theoretical first-order slope α = 1.000.

11. Precautions and limitations

  • Always check the stability restriction h < 2 / |λ_max| before running explicit Forward Euler on dissipative systems to prevent catastrophic divergence.
  • For stiff differential equations with large negative eigenvalues, use implicit Backward Euler to avoid step size collapse.
  • Ensure floating point precision remains 64-bit IEEE 754 during iterative time marching to minimize accumulated roundoff error.
  • When comparing errors across step sizes, ensure the final evaluation time T is matched exactly (t = N · h).
  • In Backward Euler, solve the implicit nonlinear equation using Newton-Raphson iteration with a convergence tolerance of 10⁻¹².
  • Do not extrapolate ODE solutions beyond the domain where the right-hand vector field f(t, y) satisfies the Lipschitz continuity condition.

Forward Euler requires very small step sizes to maintain accuracy and stability, making it computationally inefficient for precision applications.
