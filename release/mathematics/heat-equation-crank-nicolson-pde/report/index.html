4. Theory and graph choice

The mathematical modeling of diffusive transport—from transient thermal conduction in aerospace heat shields to chemical solute dispersion and financial option pricing via the Black-Scholes PDE—is governed by parabolic partial differential equations. Discretizing the heat equation ∂u/∂t = α ∂²u/∂x² with explicit forward differences leads to severe numerical instability: the time step must satisfy the crippling Courant-type condition r = α Δt / Δx² ≤ 1/2, forcing billions of tiny time steps on fine meshes. In 1947, British mathematicians John Crank and Phyllis Nicolson devised an elegant implicit formulation that averages spatial derivatives at time levels n and n + 1. By centering the stencil at t_{n+1/2}, Crank-Nicolson achieves unconditional von Neumann stability (|G| ≤ 1 for all r) and second-order accuracy O(Δt² + Δx²). In this laboratory, we implement the Crank-Nicolson scheme, invert the tridiagonal system via the Thomas algorithm, and verify the second-order O(h²) error convergence.

ln(E_max) = α · ln(h) + ln(C)

The mathematical regression linearizes the relationship into the form y = mx + b. Here, the independent variable x represents Logarithmic Mesh Spacing ln(h), and the dependent variable y represents Logarithmic Global Error ln(E_max). The slope m directly extracts Crank-Nicolson Convergence Order (α), while the intercept b accounts for residual baseline offsets.

5. Method

  1. Set up ∂u/∂t = ∂²u/∂x² on [0, π] with initial condition u(x, 0) = sin(x) and exact solution u(x, t) = e^{-t} sin(x).
  2. For test levels k = 1 to 6, set spatial grid spacing h = Δx = 0.20 / 2^{k-1} and time step Δt proportional to h.
  3. Construct tridiagonal matrices with diagonal 1 + r and off-diagonals -r/2 on the left, and diagonal 1 - r and off-diagonals r/2 on the right.
  4. At each time step t_n → t_{n+1}, multiply current state by right matrix and solve tridiagonal system via the Thomas algorithm.
  5. At final time t = 0.5, compute absolute errors |u(x_i, 0.5) - u_i^N| across all nodes and extract supremum error E_max.
  6. Plot ln(E_max) versus ln(h) and compute the linear regression gradient to verify α = 2.000 with R² = 1.000000.

11. Precautions and limitations

  • Verify that the tridiagonal matrix diagonal 1 + r strictly exceeds off-diagonal sums to preserve strict diagonal dominance in the Thomas algorithm.
  • Incorporate Dirichlet boundary values into the right-hand vector to prevent artificial boundary reflection errors.
  • Be cautious of very large diffusion numbers r > 10 when initial data has sharp discontinuities, as G ≈ -1 can induce spurious oscillations.
  • Ensure floating point precision remains 64-bit IEEE 754 to prevent roundoff accumulation across hundreds of implicit time steps.
  • Verify that spatial node count N and time step count M are updated consistently to maintain the chosen scaling relation r = Δt / Δx².
  • For non-linear thermal conductivity α(u), solve the resulting non-linear tridiagonal system using Picard or Newton-Raphson iteration.

While Crank-Nicolson is A-stable, it is not L-stable: it does not damp stiff high-frequency error components as rapidly as backward Euler or BDF2.
