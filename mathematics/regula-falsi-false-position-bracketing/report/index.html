1. Title and aim

Root Bracketing and Convergence of the Regula Falsi Method. Determine the root of f(x) = x³ − 5x + 1 = 0 on [0.0, 1.0] using the classical Regula Falsi (false position) method, investigate one-sided endpoint stagnation, evaluate the Illinois acceleration algorithm, and extract the superlinear convergence order α = 1.442 via linear regression.

4. Theory and graph choice

The Regula Falsi method—Latin for 'rule of false position'—is an ancient root-finding algorithm whose origins trace back to Egyptian, Babylonian, and Chinese mathematics (appearing in the Han Dynasty text 'The Nine Chapters on the Mathematical Art', circa 150 BCE). While modern calculus formalizes it as a hybrid of bisection and the secant method, its core intuition is simple and compelling: rather than blindly bisecting an interval at its midpoint without regard to function values, why not connect the two endpoints (a, f(a)) and (b, f(b)) with a straight line and estimate the root where this secant chord crosses the horizontal axis? The resulting false-position iterate c = [a·f(b) − b·f(a)] / [f(b) − f(a)] biases the search toward the endpoint that is closer to zero. By preserving Bolzano's sign-change condition (f(a) · f(b) < 0), Regula Falsi retains the absolute global convergence guarantee of bisection while attempting to achieve the faster speed of linear interpolation. However, in the 19th and 20th centuries, numerical analysts discovered a fatal flaw in the classical algorithm: endpoint stagnation. When f(x) exhibits consistent convexity or concavity, all chords fall on one side of the curve, causing the same endpoint to be replaced indefinitely while the other remains frozen. To resolve this stagnation, mathematicians at the University of Illinois in 1971 introduced the Illinois algorithm: whenever an endpoint is retained for two consecutive steps, its function value is halved: f(a) ← f(a)/2. This simple modification tilts the secant line, forcing the next iterate to cross over to the opposite side of the root, restoring superlinear convergence with order α = 3^(1/3) ≈ 1.442. In this laboratory investigation, students evaluate Regula Falsi and the Illinois algorithm applied to f(x) = x³ − 5x + 1 = 0 on [0, 1]. By tracking interval endpoints, demonstrating stagnation breaking, and performing logarithmic linear regression, students extract the theoretical superlinear convergence exponent α = 1.442, proving how algorithmic modifications eliminate pathological stagnation in numerical mathematics.

\ln(\varepsilon_{k+1}) = \alpha \cdot \ln(\varepsilon_k) + \ln(C) \implies \alpha = 3^{1/3} \approx 1.442

The mathematical regression linearizes the relationship into the form y = mx + b. Here, the independent variable x represents Natural Log of Current Error ln(ε_k), and the dependent variable y represents Natural Log of Next Error ln(ε_{k+1}). The slope m directly extracts Illinois Convergence Order α, while the intercept b accounts for residual baseline offsets.

5. Method

  1. Evaluate f(0.0) = +1.000 > 0 and f(1.0) = −3.000 < 0. Bolzano's Theorem guarantees a root in [0.0, 1.0].
  2. Compute c₁ = [0·(−3) − 1·(1)] / [−3 − 1] = −1 / −4 = 0.250000. Evaluate f(c₁) = (0.25)³ − 5(0.25) + 1 = 0.015625 − 1.25 + 1 = −0.234375 < 0. Update [a₁, b₁] = [0.0, 0.25].
  3. Observe that if classical Regula Falsi is applied, the convex curvature of f(x) causes left bound a = 0 to remain fixed while b crawls slowly toward x*, resulting in sluggish linear convergence.
  4. Apply the Illinois algorithm: because the right endpoint replaced b twice consecutively, replace f(a) with f(a)/2 = 0.500. Compute new chord root c₂ = [0·(−0.2344) − 0.25·(0.5)] / [−0.2344 − 0.5] = −0.125 / −0.7344 = 0.2038.
  5. Subsequent Illinois iterations yield c₃ = 0.201642 and c₄ = 0.20163767, rapidly accelerating error reduction.
  6. Perform linear regression of ln(ε_{k+1}) against ln(ε_k). Extract empirical order α = 1.442, matching the theoretical Illinois superlinear convergence order α = 3^(1/3) ≈ 1.442.

11. Precautions and limitations

  • Never use classical unaccelerated Regula Falsi on functions with strong curvature; always use Illinois or Anderson-Björck acceleration.
  • Do not terminate based exclusively on (b − a) < ε in unaccelerated Regula Falsi; verify |f(c)| < ε.
  • Confirm that f(a) · f(b) < 0 holds strictly before beginning iterations.
  • Guard against near-zero denominators f(b) − f(a) to avoid division by zero.
  • Ensure that function scaling in the Illinois step applies only to the interpolation formula, not to the true function evaluations.
  • Maintain full 64-bit IEEE 754 precision to avoid rounding errors when interval bounds draw close.
