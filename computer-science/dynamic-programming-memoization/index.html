Algorithmic assumptions and limits

The simulated execution environment models idealized state transitions where every table cell evaluation executes with deterministic cost of 1 operation (T(n) = n · W). In physical semiconductor microprocessors, wall-clock execution latency is modulated by CPU L1/L2 data cache hit ratios during row-major array streaming, branch predictor stalls during capacity feasibility checks (w ≥ w_i), hardware memory bus saturation during large matrix allocations, and operating system page table faults. In Bottom-Up Tabulation of the 0/1 Knapsack problem with fixed capacity W = 100 weight units, every subproblem cell DP[i][w] across the (n + 1) × (W + 1) state matrix is computed exactly once in O(1) time using the Bellman recurrence relation. Across n items, the total number of elementary state transition evaluations scales as T(n) = W · n = 100.0000 · n operations with exact theoretical intercept T_0 = 0.0000 states.

FOLLOW THE METHOD

A reason behind every step.

To investigate the fundamental mechanisms of Dynamic Programming (Optimal Substructure and Overlapping Subproblems), quantitatively contrast Top-Down Memoization against Bottom-Up Tabulation, analyze memory hierarchy cache locality across 2D matrix vs. 1D rolling array representations, and verify the pseudo-polynomial complexity scaling law T(n) = n · W = 100.0000 · n operations across knapsack capacity W = 100. Suggested independent settings: 10, 20, 30, 50, 75, 100, 150 items.

01

State Space Allocation & Sentinel Table Initialization

Allocate a contiguous 2D tabulation matrix of dimensions (n + 1) × (W + 1) for n items and capacity budget W = 100. Initialize all boundary base-case entries DP[0][w] = 0 and DP[i][0] = 0, and pre-fill memoization buffers with sentinel -1.

02

Top-Down Memoized Recursion Benchmark

Invoke the recursive solver for target state DP(n, W). At each call, inspect the memo table: return the cached value immediately upon a cache hit (O(1)), or evaluate subproblem branches (exclude item i vs. include item i) and write the result into the table.

03

Bottom-Up Iterative Tabulation Execution

Execute the dual nested loops (i from 1 to n, w from 0 to W) in row-major memory order. Evaluate the Bellman recurrence relation for each cell and increment the deterministic state evaluation counter.

04

Optimal Item Subset Backtracking Reconstruction

Trace backward from cell DP[n][W] to determine the exact optimal binary selection vector x ∈ {0, 1}^n. If DP[i][w] ≠ DP[i-1][w], mark item i as included (x_i = 1) and decrement remaining capacity w ← w - w_i; otherwise mark x_i = 0.

05

Space Optimization via 1D Reverse Scanning

Allocate a compact 1D array of length W + 1. For each item i, iterate capacity w backward from W down to w_i, updating DP[w] = max(DP[w], DP[w - w_i] + v_i) to demonstrate Θ(W) memory compression.

06

Asymptotic Linear Regression & Complexity Verification

Record total state evaluations across item scales n ∈ [10, 20, 30, 50, 75, 100, 150]. Regress total evaluations T(n) against item count n to compute slope k_dp, intercept T_0, and coefficient of determination R².
