4. Theory and graph choice

The Brent-Dekker algorithm—often referred to simply as Brent's method—is widely celebrated as the crowning achievement in one-dimensional root-finding. In the early decades of scientific computing, numerical analysts faced an intractable dilemma: bracketing algorithms like bisection were guaranteed to converge unconditionally from any starting interval, but their linear convergence (rate = 0.5) was painfully sluggish. Conversely, open methods like Newton-Raphson and the secant method boasted dazzling quadratic and superlinear convergence speeds, but were prone to catastrophic failure: vanishing derivatives, wild extrapolations, infinite limit cycles, and outright divergence. In 1969, Dutch mathematician Theodorus Dekker took the first major step toward synthesizing these approaches by combining bisection with linear interpolation. However, Dekker's method could still stall on pathological functions. In 1973, Australian computer scientist Richard P. Brent published his landmark monograph 'Algorithms for Minimization without Derivatives', introducing a masterfully robust hybrid framework. Brent's algorithm combines three distinct numerical strategies: (1) Bisection for foolproof global safety; (2) the Secant method for two-point linear acceleration; and (3) Inverse Quadratic Interpolation (IQI) for three-point parabolic acceleration. Instead of fitting y as a function of x and solving a quadratic equation (which requires radicals), IQI treats x as a quadratic polynomial in y: x = Q(y). Setting y = 0 yields the root estimate Q(0) in a single direct evaluation without square roots. What elevates Brent's method into an algorithmic masterpiece is its rigorous decision logic: it monitors five strict mathematical conditions governing step size and bracket reduction. If an IQI or secant step attempts to project outside the bracket, or fails to decrease the interval width by at least half over two consecutive iterations, the algorithm immediately overrides the interpolation and forces a bisection step. Consequently, Brent's method guarantees that in the worst possible mathematical case, it converges no slower than bisection, while in standard scientific practice it converges at the superlinear Tribonacci order α ≈ 1.839 with only one function evaluation per step. Today, Brent's method serves as the default industry-standard root-finding engine in software environments worldwide, including MATLAB (fzero), SciPy (brentq), and GNU Octave. In this computational laboratory, students investigate Brent's method applied to the transcendental equation f(x) = e^x − 3x² = 0 on [0.5, 1.5], trace the dynamic transitions between bisection and IQI, and extract the empirical convergence order α = 1.839 via logarithmic linear regression.

\ln(\varepsilon_{k+1}) = \alpha \cdot \ln(\varepsilon_k) + \ln(C) \implies \alpha \approx 1.839

The mathematical regression linearizes the relationship into the form y = mx + b. Here, the independent variable x represents Natural Log of Current Error ln(ε_k), and the dependent variable y represents Natural Log of Next Error ln(ε_{k+1}). The slope m directly extracts Superlinear Convergence Order α, while the intercept b accounts for residual baseline offsets.

5. Method

  1. Evaluate f(0.5) = +0.89872 > 0 and f(1.5) = −2.26831 < 0. Bolzano's theorem guarantees a root in [0.5, 1.5]. Assign a = 0.5, b = 1.5, c = a.
  2. Because f(a) ≠ f(c) does not hold (only two points available), execute 2-point secant interpolation. Candidate step s = b − f(b)·(b − a)/(f(b) − f(a)) = 1.5 − (−2.268)·(1.0)/(−3.167) = 0.7836. Check Brent conditions: s is within bounds and step size is acceptable; accept secant step.
  3. Now three distinct points exist: a, b, c with f(a), f(b), f(c) all distinct. Execute Inverse Quadratic Interpolation (IQI) fitting x as a quadratic in y. Candidate root yields b₂ = 0.9150.
  4. Evaluate f(b₂) = −0.0152. IQI conditions hold: iteration 3 yields b₃ = 0.910020 (ε₃ = 1.24 × 10⁻⁵); iteration 4 yields b₄ = 0.91000758 (ε₄ = 7.5 × 10⁻⁹).
  5. Iteration 5 yields b₅ = 0.910007572489 with ε₅ = 2.0 × 10⁻¹⁶. Algorithm terminates satisfying tolerance |b − a| ≤ 2·ε_mach·|b| + tol.
  6. Perform ordinary least-squares regression of ln(ε_{k+1}) against ln(ε_k) during the IQI phase. Extract empirical slope α = 1.83928, verifying the theoretical superlinear IQI convergence order α ≈ 1.839.

11. Precautions and limitations

  • Verify that initial bounds [a₀, b₀] strictly satisfy Bolzano's sign-change condition f(a)·f(b) < 0.
  • Always sort variables so that b represents the current best estimate satisfying |f(b)| ≤ |f(a)|.
  • Verify that all three function values f(a), f(b), f(c) are distinct before attempting Inverse Quadratic Interpolation.
  • Enforce a numerical tolerance tol = 2·ε_mach·|b| + 0.5·tol_abs to prevent infinite loops caused by floating-point granularity.
  • Ensure that candidate interpolation steps fall strictly inside the current bracket before accepting them.
  • Maintain full 64-bit IEEE 754 precision throughout all calculations.
