1. Title and aim

Pseudo-Random Number Generation: Inverse Transform and Acceptance-Rejection Sampling. Investigate fundamental stochastic simulation algorithms, implement the Inverse Transform method for invertible CDFs, construct Von Neumann Acceptance-Rejection sampling for complex target densities, and measure bounding envelope efficiency.

Six statistical trials were executed across standardized inputs Quota Scale k = 1.0 to Quota Scale k = 6.0 for Pseudo-Random Number Generation: Inverse Transform and Acceptance-Rejection Sampling. 3. Apparatus and fixed settings

  • Uniform Pseudo-Random Core: Generates high-quality uniform random variates U ~ U[0, 1] using the 64-bit Xoshiro256** algorithm.
  • Inverse CDF Analytical Inverter: Generates non-uniform variates X = F^(-1)(U) for analytically invertible cumulative distributions.
  • Von Neumann Envelope Generator: Constructs proposal densities g(x) and bounding scale constants c = sup [f(x)/g(x)] to form majorizing envelopes.
  • Acceptance-Rejection Decision Unit: Applies the stochastic filter: accept proposal Y ~ g if U ≤ f(Y) / (c g(Y)); reject and repeat otherwise.
  • Sampling Efficiency Meter: Measures the empirical acceptance rate P(Accept) = 1/c and computes proposal overhead.
  • Proposal Overhead Regression Engine: Performs linear regression of total candidate proposals versus accepted sample quota to extract envelope factor c = 1.500.
  • Target density f(x) = 6x(1-x) on [0, 1] (Beta(2, 2))
  • Proposal distribution g(x) = Uniform[0, 1] with c = 1.50

4. Theory and graph choice

Pseudo-random variate generation is the operational backbone of computational statistics, stochastic modeling, and Monte Carlo simulation. While the Inverse Transform method provides an exact, zero-rejection framework for analytically invertible cumulative distributions, John von Neumann's Acceptance-Rejection algorithm provides a universal mechanism for sampling from complex, non-invertible target distributions using majorizing envelopes. In this laboratory, we implement inverse transform sampling, construct optimal acceptance-rejection envelopes, analyze geometric proposal overhead, and confirm the bounding constant scaling slope m = 1.500. In mathematical statistics, empirical data science, and modern computational engineering, understanding the asymptotic sampling properties and theoretical behavior of Pseudo-Random Number Generation: Inverse Transform and Acceptance-Rejection Sampling provides crucial guarantees. Rigorous experimental validation connects foundational probability laws with observable empirical phenomena, ensuring that statistical inference remains valid under finite sample sizes and real-world data collection constraints.

5. Method

  1. Specify target probability density f(x) = 6x(1-x) on [0, 1] (Beta(2, 2) distribution) and proposal density g(x) = 1 (Uniform U[0, 1]) on the simulation dashboard.
  2. Differentiate the ratio f(x)/g(x) = 6x - 6x^2 to find the maximum at x = 0.5: c = sup [f(x)/g(x)] = 6(0.5)(1 - 0.5) = 1.500.
  3. In the comparison module, draw U ~ U[0, 1] and evaluate X = -ln(1 - U) / λ. Verify that the resulting sample follows the Exponential distribution with 100% acceptance efficiency.
  4. Draw candidate Y ~ U[0, 1] and test threshold U_2 ~ U[0, 1]. Accept Y if U_2 ≤ f(Y) / (c g(Y)) = 6Y(1-Y)/1.5 = 4Y(1-Y). Count accepted variates and rejected proposals.
  5. Increment accepted quota across standardized settings N_target = 1,000 · k for k ∈ {1, 2, 3, 4, 5, 6}, recording total candidate proposals N_prop evaluated.
  6. Fit a linear regression model y = mx to the coordinate pairs (x = k, y = N_prop / 1000). Confirm that empirical slope m = 1.5000 rigorously recovers the bounding constant c = 1.500.

11. Precautions and limitations

  • Ensure the bounding condition f(x) ≤ c g(x) holds strictly across the entire support domain to avoid distribution distortion.
  • Verify that uniform variates U_1 (for proposal) and U_2 (for acceptance test) are drawn from independent random streams.
  • Check that the proposal density g(x) has tails at least as heavy as target density f(x) to prevent c from diverging to infinity.
  • Monitor acceptance rates continuously during long simulation runs to detect potential numerical envelope violations.

Acceptance-rejection sampling becomes computationally inefficient in high-dimensional parameter spaces (curse of dimensionality).
