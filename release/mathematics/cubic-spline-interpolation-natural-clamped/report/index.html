3. Apparatus and fixed settings

  • Piecewise Knot Mesh Discretizer: Divides the domain into N sub-intervals with knot coordinates x_0 < x_1 < ... < x_N and spacing h_i = x_{i+1} - x_i.
  • C² Continuity Matrix Assembler: Formulates the tridiagonal system for second derivatives M_i = S''(x_i) based on slope matching at interior knots.
  • Thomas Algorithm Engine: Solves the symmetric, strictly diagonally dominant tridiagonal system in O(N) operations without pivoting.
  • Boundary Condition Switcher: Applies either natural free-edge constraints (M_0 = M_N = 0) or clamped derivative constraints.
  • Piecewise Hermite Cubic Evaluator: Interpolates any query point x within its respective knot interval using the local cubic polynomial representation.
  • Curvature Energy Integrator: Computes the total bending energy ∫ (S''(x))² dx to verify the Holladay minimum curvature variational property.
  • Continuity requirement: Piecewise cubic polynomials S_i(x) with S ∈ C²[a, b] (continuous value, slope, and curvature)
  • Tridiagonal solver: Thomas algorithm (TDMA) with O(N) computational complexity and strict diagonal dominance
  • Boundary condition modes: Natural spline (S''(a) = S''(b) = 0) and Clamped spline (S'(a) = f'(a), S'(b) = f'(b))
  • Underlying objective curve: Test manifold f(x) = exp(x) · sin(2πx) on [0, 1]

4. Theory and graph choice

While global polynomial interpolation attempts to fit a single high-degree polynomial through all data points—often incurring Runge's wild boundary oscillations—spline interpolation adopts a piecewise paradigm. Originating from the physical flexible wooden splines used by naval draftsmen to draw smooth ship hulls, mathematical cubic splines connect adjacent data pairs using cubic polynomials joined with C² continuity (matching values, first derivatives, and second derivatives). The resulting system of continuity equations is tridiagonal and strictly diagonally dominant, enabling direct solution in linear O(N) time via the Thomas algorithm. In this laboratory, we construct natural and clamped cubic splines, examine the tridiagonal curvature system, and confirm the optimal O(h⁴) error convergence rate.

ln(E_max) = α · ln(h) + ln(C)

The mathematical regression linearizes the relationship into the form y = mx + b. Here, the independent variable x represents Logarithmic Mesh Spacing ln(h), and the dependent variable y represents Logarithmic Spline Error ln(E_max). The slope m directly extracts Spline Convergence Order (α), while the intercept b accounts for residual baseline offsets.

5. Method

  1. Set up N = 2^{k+1} knot intervals on [0, 1] with uniform spacing h = 1.0 / N across refinement levels k = 1 to 6.
  2. Compute exact function ordinates y_i = f(x_i) at all knots x_i = i · h for i = 0, ..., N.
  3. Set up the continuity equations h_{i-1} M_{i-1} + 2(h_{i-1} + h_i) M_i + h_i M_{i+1} = 6[(y_{i+1} - y_i)/h_i - (y_i - y_{i-1})/h_{i-1}].
  4. Apply clamped boundary conditions and execute the forward elimination and backward substitution of the Thomas algorithm to obtain all moments M_i.
  5. Sample S(x) across 1500 interior points and extract the maximum absolute deviation E_max = ||f - S||_∞.
  6. Plot ln(E_max) versus ln(h) and perform linear regression to quantitatively confirm the theoretical order α = 4.000.

11. Precautions and limitations

  • Ensure knot coordinates x_0 < x_1 < ... < x_N are strictly monotonically increasing before assembling the tridiagonal matrix.
  • Verify diagonal dominance when setting custom boundary conditions; clamped conditions preserve strict diagonal dominance.
  • In the Thomas algorithm, check for division by near-zero pivot elements, though strict diagonal dominance theoretically guarantees non-zero pivots.
  • When querying an interpolant at point x, use binary search (std::upper_bound) in O(log N) time to locate the knot interval [x_i, x_{i+1}].
  • Store the moments M_i and compute local cubic coefficients a_i, b_i, c_i, d_i explicitly to allow fast repeated point evaluations.
  • Ensure floating point precision buffer remains 64-bit IEEE 754 to prevent error accumulation in the backward substitution phase.
