4. Theory and graph choice

The Singular Value Decomposition (SVD)—originating in the independent mathematical investigations of Eugenio Beltrami (1873), Camille Jordan (1874), and James Joseph Sylvester (1889), and elevated to an algorithmic triumph by Gene Golub and William Kahan in 1965—is universally acknowledged as the absolute summit of matrix computations. In linear algebra, eigendecomposition A = VΛV⁻¹ is restricted exclusively to square, diagonalizable matrices, and can become severely ill-conditioned if eigenvectors are nearly collinear. SVD transcends all such limitations: every matrix—square or rectangular, full-rank or rank-deficient, well-conditioned or pathological—admits an SVD: A = UΣVᵀ. Here, U is an m×m orthogonal matrix containing the left singular vectors, V is an n×n orthogonal matrix containing the right singular vectors, and Σ is an m×n diagonal matrix containing the non-negative singular values sorted in descending order: σ₁ ≥ σ₂ ≥ ... ≥ σ_p ≥ 0. Geometrically, SVD decomposes any linear transformation into three elementary geometric actions: an initial rotation in the domain (Vᵀ), an axis-aligned stretching by factors σ_i (Σ), and a final rotation in the codomain (U). In computational science, SVD provides the definitive definition of matrix condition: the 2-norm condition number is given exactly by κ₂(A) = σ_max / σ_min. Furthermore, SVD resolves the universal problem of inverting non-invertible matrices via the Moore-Penrose pseudoinverse: A⁺ = V Σ⁺ Uᵀ. For any linear system Ax = b, x_{LS} = A⁺ b produces the unique solution that simultaneously minimizes the residual error ‖Ax − b‖₂ and has the minimum Euclidean norm ‖x‖₂. Finally, by the Eckart-Young-Mirsky theorem, truncating the SVD to its top k components yields the mathematically optimal low-rank matrix approximation, providing the engine for Principal Component Analysis (PCA), latent semantic indexing, and big-data denoising. In this computational laboratory, students evaluate SVD on a matrix with singular values σ = [10.0, 4.0, 0.4] (condition number κ = 10.0/0.4 = 25.000), construct the Moore-Penrose pseudoinverse, explore rank truncation, and extract the condition number κ₂(A) = 25.000 via linear regression.

\kappa_2(A) = \frac{\sigma_{\max}}{\sigma_{\min}} = \frac{\sigma_1}{\sigma_r} = \frac{10.000}{0.400} = 25.000

The mathematical regression linearizes the relationship into the form y = mx + b. Here, the independent variable x represents Iteration Step k, and the dependent variable y represents Cumulative Condition Ratio (25.000 · k). The slope m directly extracts Matrix Condition Number κ₂(A), while the intercept b accounts for residual baseline offsets.

5. Method

  1. Initialize m×n matrix A with known singular spectrum σ = [10.000, 4.000, 0.400]. Verify that condition number κ₂(A) = 10.0 / 0.4 = 25.000.
  2. Apply alternating Householder reflections: P₁ A Q₁ ... P_n A Q_{n-2} reduces A to upper-bidiagonal form B in 4mn² − (4/3)n³ operations.
  3. Apply the Golub-Reinsch implicitly shifted QR algorithm to bidiagonal matrix B, driving off-diagonal entries to zero to extract singular values σ_i.
  4. Form diagonal matrix Σ⁺ where σ_i⁺ = 1/σ_i if σ_i > 10⁻¹², and 0 otherwise. Compute pseudoinverse A⁺ = V Σ⁺ Uᵀ.
  5. For right-hand side b, evaluate x_{LS} = A⁺ b. Confirm that x_{LS} is the unique solution minimizing both residual ‖Ax − b‖₂ and solution norm ‖x‖₂.
  6. Plot cumulative condition metric y = 25.000 · k against step k. Perform ordinary least-squares regression to extract empirical slope m = 25.000, confirming matrix condition number κ₂(A) = 25.000.

11. Precautions and limitations

  • Never form the normal equations matrix AᵀA explicitly when A is ill-conditioned; always use SVD or QR.
  • Choose singular value truncation threshold ε_tol carefully (e.g. ε_tol = max(m, n) · ε_mach · σ₁) to prevent noise amplification.
  • Verify that singular values are sorted in non-increasing order: σ₁ ≥ σ₂ ≥ ... ≥ σ_p ≥ 0.
  • Do not invert zero or near-zero singular values; set σ_i⁺ = 0 for σ_i < ε_tol.
  • Maintain 64-bit precision; Golub-Kahan bidiagonalization requires dual Householder sweeps.
  • Check that U and V are strictly orthogonal: ‖UᵀU − I‖ < 10⁻¹⁴ and ‖VᵀV − I‖ < 10⁻¹⁴.
