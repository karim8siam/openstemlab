4. Theory and graph choice

Elliptic partial differential equations govern static equilibrium, steady-state diffusion, and potential fields throughout physics and applied mathematics. In electrostatics, gravitation, steady heat conduction, and incompressible potential flow, the potential distribution satisfies Laplace's equation ∇²u = 0 or Poisson's equation ∇²u = f. Discretizing the two-dimensional Laplacian operator on a uniform Cartesian grid produces the celebrated 5-point difference star stencil. For large two-dimensional meshes, direct matrix inversion is memory-prohibitive, motivating iterative relaxation methods. While simple Jacobi relaxation updates each node as the average of its neighbors, and Gauss-Seidel accelerates convergence by immediate in-place overwriting, David Young's Successive Over-Relaxation (SOR) method introduces an over-correction factor ω that dramatically accelerates convergence. In this laboratory, we implement the 5-point Poisson stencil, analyze relaxation spectral radii, and confirm the optimal relaxation parameter ω_opt = 1.729.

y = ω_opt · k + b

The mathematical regression linearizes the relationship into the form y = mx + b. Here, the independent variable x represents Setting Index k, and the dependent variable y represents Convergence Metric y = ω_opt · k. The slope m directly extracts Optimal SOR Parameter (ω_opt), while the intercept b accounts for residual baseline offsets.

5. Method

  1. Set up ∇²u = -2 π² sin(πx) sin(πy) on [0, 1]² with homogeneous Dirichlet boundaries u = 0 and exact solution u = sin(πx) sin(πy).
  2. Allocate N = 20 interior grid points with uniform spacing h = 1/21, setting initial potential guess u_{i,j} = 0 everywhere.
  3. Run baseline iterations to observe slow asymptotic convergence governed by spectral radii ρ_J ≈ 0.9888 and ρ_{GS} = ρ_J² ≈ 0.9778.
  4. Vary relaxation factor ω from 1.0 to 1.95, measuring total iterations required to reduce residual norm below 10⁻⁶.
  5. Confirm that at ω_opt = 2 / (1 + sin(π h)) ≈ 1.729, iteration count drops from over 400 down to fewer than 35.
  6. Log the standardized relaxation response across settings k = 1 to 6 and fit linear regression to confirm target ω_opt = 1.729.

11. Precautions and limitations

  • Always verify that relaxation parameter ω lies strictly within the stable interval 0 < ω < 2 to prevent catastrophic divergence.
  • Enforce Dirichlet boundary values u = 0 at every iteration to ensure boundary conditions are strictly preserved.
  • Use Red-Black checkerboard ordering if implementing parallel relaxation on multi-threaded or GPU architectures.
  • Ensure floating point precision remains 64-bit IEEE 754 to prevent roundoff error accumulation across hundreds of relaxation sweeps.
  • Compute the discrete L₂ residual norm ||r||₂ = √(∑ (u_{star} - u)² / N²) at regular intervals to monitor convergence progress.
  • Do not terminate relaxation prematurely; verify that the maximum point-wise residual satisfies ||r||_∞ < 10⁻⁶.

Optimal SOR requires knowing the Jacobi spectral radius ρ_J in advance; for irregular domains, ρ_J must be estimated dynamically via Chebychev acceleration.
