4. Theory and graph choice

The Successive Over-Relaxation (SOR) method—developed independently in 1950 by the American mathematician David M. Young Jr. in his doctoral thesis and by Stanley P. Frankel for nuclear weapon calculations on the ENIAC—is one of the most celebrated algorithmic breakthroughs in the history of computational linear algebra. In the 1940s, solving the finite-difference equations of heat transfer and neutron diffusion was severely bottlenecked by the slow convergence of the Jacobi and Gauss-Seidel iterations. Gauss-Seidel improved upon Jacobi by immediately utilizing newly computed components x_j^{(k+1)} within the same iteration: x_i^{GS} = (b_i − ∑_{j<i} a_{ij}x_j^{(k+1)} − ∑_{j>i} a_{ij}x_j^{(k)}) / a_{ii}. However, on fine computational meshes, Gauss-Seidel error reduction is plagued by sluggishness: the updates Δx_i = x_i^{GS} − x_i^{(k)} crawl forward monotonically. Young and Frankel introduced a bold modification: why not accelerate the step by multiplying the correction by a relaxation weight ω > 1? The resulting SOR iteration formula takes the form: x_i^{(k+1)} = (1 − ω)x_i^{(k)} + (ω/a_{ii})(b_i − ∑_{j<i} a_{ij}x_j^{(k+1)} − ∑_{j>i} a_{ij}x_j^{(k)}). In matrix notation, this corresponds to the matrix splitting (D − ωL)x^{(k+1)} = [(1 − ω)D + ωU]x^{(k)} + ωb. The Ostrowski-Reich Theorem establishes that for any symmetric positive-definite matrix, SOR converges if and only if 0 < ω < 2. In a triumph of applied analysis, David Young derived an exact closed-form expression for the optimal relaxation parameter minimizing the spectral radius on 2-cyclic consistently ordered matrices: ω_opt = 2 / [1 + √(1 − ρ(T_J)²)]. By tuning ω to ω_opt, the spectral radius drops from ρ_{GS} = 1 − O(h²) to ρ_{SOR} = 1 − O(h). On a 1000×1000 grid, this reduces the required iterations from hundreds of thousands down to a few hundred, cutting computation time by several orders of magnitude. In this computational laboratory, students evaluate the SOR method applied to a linear system with Jacobi spectral radius ρ = 0.500, investigate parameter sensitivity across the stability domain ω ∈ (0, 2), and extract the theoretical optimal parameter ω_opt = 1.268 via linear regression.

\omega_{\text{opt}} = \frac{2}{1 + \sqrt{1 - \rho(T_J)^2}} = \frac{2}{1 + \sqrt{1 - 0.5^2}} \approx 1.268

The mathematical regression linearizes the relationship into the form y = mx + b. Here, the independent variable x represents Iteration Step k, and the dependent variable y represents Cumulative Relaxation Weight (ω · k). The slope m directly extracts Optimal Relaxation Parameter ω_opt, while the intercept b accounts for residual baseline offsets.

5. Method

  1. Determine the base Jacobi spectral radius ρ(T_J) = 0.500 for the target tridiagonal 2-cyclic matrix A.
  2. Apply David M. Young's theorem (1950): compute ω_opt = 2 / [1 + √(1 − ρ(T_J)²)] = 2 / [1 + √(1 − 0.25)] = 2 / [1 + √0.75] = 2 / [1 + 0.866025] = 1.267949.
  3. Set ω = 1.000 (standard Gauss-Seidel). Observe spectral radius ρ_{GS} = ρ_J² = 0.2500, requiring 4 steps to achieve 10⁻⁴ accuracy.
  4. Set ω = 1.268. Evaluate SOR iteration: spectral radius drops to ρ_{SOR} = ω_opt − 1 = 1.267949 − 1 = 0.267949, speeding convergence dramatically.
  5. Test parameter values ω ∈ {0.8, 1.0, 1.268, 1.5, 1.9}. Confirm that for ω ≥ 2, the algorithm diverges violently, verifying the Ostrowski-Reich boundary.
  6. Plot cumulative relaxation metric y = 1.268 · k against iteration step k. Extract empirical slope m = 1.2680, confirming the optimal relaxation parameter.

11. Precautions and limitations

  • Never select ω ≥ 2; the Ostrowski-Reich theorem proves that SOR is unconditionally divergent for ω ≥ 2.
  • Accurately estimate the Jacobi spectral radius ρ(T_J) before choosing ω; an inaccurate ω degrades performance back to Gauss-Seidel.
  • If using Red-Black coloring for parallel GPU execution, verify that the matrix graph is bipartite.
  • Do not use standard unsymmetric SOR as a preconditioner for Conjugate Gradient; use SSOR instead.
  • For non-symmetric systems, verify that all eigenvalues of the iteration matrix satisfy |λ| < 1.
  • Maintain 64-bit precision to prevent accumulated round-off in backward-forward sweeps.
