FOLLOW THE METHOD

A reason behind every step.

Measure compressor and turbine pressure ratios, stagnation temperatures, and thermal efficiency eta_th to evaluate real open Joule-Brayton cycle performance. Standardized parameter settings: 0.45, 0.6, 0.8, 1.0, 1.2, 1.4 dimensionless.

01

Engine Startup and Idle Stabilization

Initiate automated electric start sequence, spooling turbojet up to idle (35,000 RPM) and verifying fuel pressure.

02

Stationary Environmental Baseline

Record compressor face inlet stagnation pressure P_01 and temperature T_01 = 293.15 K.

03

Throttle Power Stepping

Advance engine throttle to establish compressor pressure parameters x = 0.45, 0.60, 0.80, 1.00, 1.20, and 1.40.

04

Cycle State Variable Acquisition

Record total pressures and temperatures at compressor exit (P_03, T_03) and turbine inlet/exit (T_04, T_05) at each plateau.

05

Compressor Work Computation

Compute actual specific work: w_c = c_p * (T_03 - T_01), and calculate isentropic efficiency eta_c.

06

Cycle Work Linear Regression

Plot specific work w_c versus pressure parameter x, perform linear regression to extract slope c_p*T_01/eta_c, and evaluate cycle efficiency.
