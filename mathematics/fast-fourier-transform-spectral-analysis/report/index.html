1. Title and aim

Fast Fourier Transform (FFT) & Cooley-Tukey O(N log N) Complexity. Implement the radix-2 decimation-in-time Cooley-Tukey Fast Fourier Transform, evaluate twiddle factor symmetries, construct the butterfly computational graph, and quantitatively verify the 5 N log₂ N floating-point operational scaling against naive O(N²) matrix multiplication.

2. Abstract

Six computational trials were executed across standardized inputs N = 64 to N = 2048 for Fast Fourier Transform (FFT) & Cooley-Tukey O(N log N) Complexity. An ordinary least-squares regression yielded an empirical FFT Operational Constant (C) of 5.000 FLOPs/NlogN (difference from theoretical reference = 0.0000%). The empirical telemetry conclusively validates the theoretical model and complexity scaling with R² = 1.000000.

3. Apparatus and fixed settings

  • Discrete Time Signal Synthesizer: Generates multi-tone complex input signals x[n] = ∑ A_m exp(2πi f_m n / N) corrupted by white noise.
  • Bit-Reversal Permutation Engine: Reorders input samples into bit-reversed sequence to enable in-place butterfly computation without auxiliary arrays.
  • Twiddle Factor Trigonometric Table: Precomputes complex roots of unity W_N^k = cos(2πk/N) - i sin(2πk/N) with 64-bit precision.
  • Radix-2 Butterfly Execution Unit: Executes the core 2-point butterfly computation: u = X[k], t = W · X[k+m], X[k] = u + t, X[k+m] = u - t.
  • FLOP Telemetry Counter: Tracks the exact count of real floating-point additions and multiplications (5 N log₂ N FLOPs total).
  • Power Spectral Density Visualizer: Computes magnitude spectrum |X[k]|² and visualizes frequency peaks and spectral resolution.
  • Algorithm architecture: Radix-2 decimation-in-time (DIT) Cooley-Tukey algorithm with in-place butterfly computation
  • Bit-reversal permutation: Precomputed bit-reversed index addressing for cache-optimized in-place execution
  • Twiddle factor symmetry: W_N^k = exp(-2πi k / N) with periodicity W_N^{k + N/2} = -W_N^k
  • Discrete Fourier transform definition: X_k = ∑_{n=0}^{N-1} x_n · exp(-2πi k n / N)

4. Theory and graph choice

Described by IEEE Spectrum as 'the most important algorithm of the twentieth century,' the Fast Fourier Transform (FFT) underpins modern digital telecommunications, radar, audio compression (MP3/AAC), image processing (JPEG), magnetic resonance imaging (MRI), and fast polynomial multiplication. Computing the Discrete Fourier Transform directly demands N² complex multiply-add operations, rendering real-time digital signal processing impossible for large data streams. In 1965, James Cooley and John Tukey published their divide-and-conquer factorization—unwittingly rediscovering an algorithm conceived by Carl Friedrich Gauss in 1805—which slashed complexity from O(N²) to O(N log₂ N). In this computational laboratory, we implement the radix-2 Cooley-Tukey algorithm, construct the butterfly computational graph, examine twiddle factor anti-symmetry, and verify the 5 N log₂ N floating-point operational scaling.

FLOPs(N) = C · (N log₂(N) / 1000) + b

The mathematical regression linearizes the relationship into the form y = mx + b. Here, the independent variable x represents Normalized Complexity Coordinate (N log₂(N) / 1000), and the dependent variable y represents Measured Floating-Point Operations (kFLOPs). The slope m directly extracts FFT Operational Constant (C), while the intercept b accounts for residual baseline offsets.

5. Method

  1. Set transform size N as a power of two (N ∈ {64, 128, 256, 512, 1024, 2048}) and synthesize test signal x[n].
  2. Permute the complex input array in-place by swapping each element with its bit-reversed index mirror.
  3. Execute stage loop s = 1 to log₂(N), doubling butterfly sub-transform length m = 2^s at each stage.
  4. For each sub-transform, multiply lower branch by twiddle factor W_m^j and perform complex add/subtract.
  5. Record total floating-point operations (each complex butterfly requires 1 complex multiply [6 FLOPs] and 2 complex adds [4 FLOPs], averaging 5 N log₂ N real operations).
  6. Plot measured kFLOPs versus normalized coordinate (N log₂(N) / 1000) and perform linear regression to confirm C = 5.000.

9. Uncertainty and comparison

Percentage difference = |estimate − theoretical value| / |theoretical value| × 100 = 0.0000%.

For n = 6 observations, Σresidual² = 4.5438e-28; s² = Σresidual²/(n − 2). Gradient standard error = √[s²/Σ(x − x̄)²] = 5.5971e-16. Intercept standard error = √[s²(1/n + x̄²/Σ(x − x̄)²)] = 5.7750e-15.

11. Precautions and limitations

  • Verify that transform size N is an exact power of two (N = 2^p); pad with trailing zeros if input signal length is arbitrary.
  • Precompute twiddle factor trigonometric tables W_N^k once to avoid repeated slow sin() and cos() calls in inner butterfly loops.
  • Implement bit-reversal in-place by swapping only when index i < bit_reverse(i) to prevent double-swapping back to original order.
  • Ensure floating point precision remains 64-bit IEEE 754 to prevent roundoff accumulation across log₂(N) butterfly stages.
  • Normalize the inverse FFT by 1/N to satisfy the unitary energy preservation property of Parseval's theorem.
  • Apply appropriate windowing (such as Hanning) to non-periodic signals to suppress spectral leakage sidelobes.

Radix-2 FFT requires transform lengths equal to exact powers of two; prime-length DFTs require Bluestein's algorithm or Rader's algorithm. The simulation evaluates the radix-2 Cooley-Tukey FFT across transform sizes N = 64 to 2048. Floating-point operation counts scale linearly with the normalized complexity coordinate N log₂(N)/1000, confirming the theoretical operational constant C = 5.000 with R² = 1.000000.
