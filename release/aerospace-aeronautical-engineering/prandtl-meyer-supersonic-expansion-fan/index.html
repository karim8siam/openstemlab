FOLLOW THE METHOD

A reason behind every step.

Map Mach number increase and static pressure drop across a sharp convex expansion corner to evaluate the Prandtl-Meyer function nu(M). Standardized parameter settings: 3.0, 6.0, 9.0, 12.0, 15.0, 18.0 deg.

01

Corner Model Alignment

Install the theta = 3.0 degree convex corner model into the optical test section, aligning the upstream floor with the nozzle exit.

02

Schlieren Wave Verification

Initiate supersonic blowdown at M_1 = 1.80, verifying through Schlieren optics that the leading expansion wave is inclined at mu_1 = arcsin(1/1.80) = 33.75 deg.

03

Upstream Baseline Acquisition

Record upstream reference static pressure P_1 and stagnation pressure P_01 ahead of the expansion corner.

04

Downstream Pressure Mapping

Acquire downstream wall static pressures P_2 at fully expanded stations for convex angles theta = 3.0, 6.0, 9.0, 12.0, 15.0, and 18.0 degrees.

05

Mach Number Computation

Compute downstream Mach number M_2 using the isentropic relation: M_2 = sqrt(5 * [(P_01/P_2)^(2/7) - 1]) and compute Delta M = M_2 - M_1.

06

Prandtl-Meyer Linear Regression

Plot Delta M versus theta, perform linear regression to determine the expansion rate dM / dtheta, and compare with the theoretical Prandtl-Meyer derivative.
