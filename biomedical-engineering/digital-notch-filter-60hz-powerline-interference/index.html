FOLLOW THE METHOD

A reason behind every step.

Design and implement a second-order IIR notch filter (Q = 30) to suppress 60 Hz hum from corrupted ECG telemetry while preserving diagnostic ST-segment and QRS morphology. Standardized parameter settings: 0.1, 0.3, 0.5, 0.7, 0.9, 1.1 mV².

01

Filter Coefficient Calculation and DSP Initialization

Compute second-order IIR notch coefficients for f_0 = 60.0 Hz, f_s = 500 Hz, Q = 30: b = [1, -2·cos(ω_0), 1], a = [1, -2·r·cos(ω_0), r²] with r = 0.9874; load into DSP memory.

02

Clean ECG Baseline Reference

Input pure clean 1.0 mV ECG waveform without noise; confirm that filter passband causes zero visible attenuation or phase distortion of the QRS complex.

03

Initial 60 Hz Noise Injection (P_in = 0.10 mV²)

Superimpose 60.0 Hz sinusoidal hum to establish an input noise power P_in = 0.10 mV² (amplitude ~0.45 mV peak-to-peak).

04

Residual Filtered Power Acquisition

Run real-time biquad filtering and compute FFT power spectral density at 60 Hz; log residual output power P_out in μV².

05

Noise Power Progression Sequence

Increment 60 Hz interference power through 0.30, 0.50, 0.70, 0.90, and 1.10 mV², recording residual output power P_out at each step.

06

Rejection Ratio Regression Analysis

Plot residual output power P_out against input interference power P_in, performing linear regression to evaluate the power transmission ratio k_n.
