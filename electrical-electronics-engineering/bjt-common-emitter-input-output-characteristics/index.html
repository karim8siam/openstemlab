FOLLOW THE METHOD

A reason behind every step.

Plot input (I_B vs V_BE) and output (I_C vs V_CE) static characteristic curves of an NPN BJT in common-emitter configuration, evaluating current gain (beta), input resistance (h_ie), and output conductance (h_oe). Standardized parameter settings: 10.0, 20.0, 30.0, 40.0, 50.0, 60.0 μA.

  1. Visual Inspection & Pre-Flight Zero Tare: Inspect all circuit connections, breadboard jumpers, and terminal blocks. Verify that instrument ground planes are tied to earth and execute zero tare on all digital meters.
  2. Excitation Source & Baseline Calibration: Energize the regulated supply, set baseline operating thresholds, and calibrate the base current i_b using the precision standard reference meter.
  3. Systematic Parameter Variation & Settling: Increment the base current i_b systematically across the designated experimental range (10.0 to 60.0 μA), permitting thermal settling at each setpoint.
  4. Multi-Meter & Oscilloscope Waveform Acquisition: Record the primary output metric (Collector Current I_C) alongside auxiliary telemetry. Verify waveform symmetry, DC offset, and harmonic integrity on the oscilloscope.
  5. Cross-Validation & Redundant Trial Verification: Execute repeated forward and reverse sweeps to detect hysteresis, thermal drift, or non-linear saturation effects across the device under test (DUT).
  6. Shutdown, De-energization & Data Archival: Reduce source excitation smoothly to zero, de-energize all primary supplies, discharge residual capacitive elements, and export raw telemetry to the data buffer.
