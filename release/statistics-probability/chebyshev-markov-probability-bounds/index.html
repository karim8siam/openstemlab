FOLLOW THE METHOD

A reason behind every step.

Evaluate empirical tail probabilities across diverse probability distributions, compare empirical tail frequencies against Markov's and Chebyshev's upper bounds, and verify the inverse-square power law. Standardized parameter settings: 1.5, 2.0, 2.5, 3.0, 3.5, 4.0 k.

01

Configure Target Distribution and Sample Buffer

Select a continuous distribution with verified finite variance (e.g., standard normal N(0, 1) or standardized Exponential) and draw N = 100,000 observations.

02

Standardize Sample Deviations

For each sample observation, compute the standardized absolute deviation Z_i = |X_i - μ| / σ and sort the array to facilitate rapid tail searching.

03

Evaluate Tail Frequency for Deviation Multiple k = 1.5

Set k = 1.5. Calculate the theoretical Chebyshev upper bound P_bound = 1 / k² = 1 / (1.5)^2 = 0.4444. Count the empirical fraction of observations exceeding 1.5σ.

04

Verify Markov Bound on Squared Deviations

Confirm that applying Markov's inequality to the non-negative variable Y = (X - μ)² yields P(Y ≥ k²σ²) ≤ E[Y] / (k²σ²) = σ² / (k²σ²) = 1/k², deriving Chebyshev's inequality.

05

Step Deviation Multiple k Across 1.5 to 4.0

Increment k across standardized values k ∈ {1.5, 2.0, 2.5, 3.0, 3.5, 4.0}, recording the steep decay of both empirical tail frequencies and the theoretical 1/k² bound.

06

Execute Log-Log Regression on the Upper Bound

Fit a linear regression model to the coordinates (x = ln(k), y = ln(1/k²)). Confirm that the empirical gradient m = -2.0000 exactly verifies the inverse-square concentration scaling.
