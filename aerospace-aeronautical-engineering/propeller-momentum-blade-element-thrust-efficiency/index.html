Aeronautical assumptions and boundary condition limits

Blade Element Momentum Theory (BEMT) assumes steady axisymmetric inflow without blade tip vortex compressibility. Linear regression of the thrust coefficient deficit against advance ratio yields a slope dC_T/dJ = 0.1350 with R^2 > 0.999999.

FOLLOW THE METHOD

A reason behind every step.

Measure propeller thrust coefficient C_T, power coefficient C_P, and propulsive efficiency eta_p across advance ratios J = V / (n D) to evaluate blade element theory. Standardized parameter settings: 0.3, 0.4, 0.5, 0.6, 0.7, 0.8 dimensionless.

01

Propeller Static Tare Calibration

Set wind tunnel speed to zero, spin up propeller to static RPM, and verify static thrust coefficient C_T0 = 0.1250.

02

Rotational Speed Stabilization

Set motor speed to constant n = 50.0 rev/s (3000 RPM) using the closed-loop optical tachometer.

03

Wind Tunnel Airspeed Stepping

Step wind tunnel velocity through V_inf = 4.5, 6.0, 7.5, 9.0, 10.5, and 12.0 m/s (corresponding to J = 0.30 to 0.80).

04

Thrust and Torque Acquisition

Sample 3000 points of axial thrust T and torque Q at each advance ratio plateau.

05

Non-Dimensional Coefficient Computation

Calculate non-dimensional thrust coefficient C_T and power coefficient C_P, computing propulsive efficiency eta_p.

06

Propeller Slope Linear Regression

Plot thrust deficit (C_T0 - C_T) versus J, perform linear regression to determine slope dC_T / dJ, and find zero-thrust advance ratio J_0.
