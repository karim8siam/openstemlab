3. Apparatus and fixed settings

  • One-Dimensional Domain Discretizer: Partitions [0, 1] into N sub-intervals with uniform grid spacing h = 1/N and interior nodes x_i = i · h.
  • Central Difference Stencil Generator: Replaces derivatives with second-order central difference operators: y' ≈ (y_{i+1} - y_{i-1})/(2h), y'' ≈ (y_{i+1} - 2y_i + y_{i-1})/h².
  • Tridiagonal Matrix Assembler: Constructs the sparse banded coefficient matrix A and load vector b incorporating Dirichlet boundary data.
  • Thomas Algorithm Solver: Solves the symmetric strictly diagonally dominant tridiagonal BVP system in O(N) operations without pivoting.
  • Analytic Reference Evaluator: Computes exact closed-form solution y(x) = 4x + (sinh(2x) / sinh(2)) · (4 - 4) ... to measure exact nodal errors.
  • Log-Log Error Convergence Engine: Performs linear regression on (ln(h), ln(E_max)) to verify the theoretical second-order slope α = 2.000.
  • Model differential equation: -y''(x) + 4 y(x) = 16 x, on x ∈ [0, 1] with Dirichlet boundary conditions y(0) = 0, y(1) = 4
  • Central difference stencil: y''(x_i) ≈ (y_{i-1} - 2 y_i + y_{i+1}) / h² with local truncation error O(h²)
  • Discrete matrix system: Tridiagonal matrix A y = b with diagonal 2/h² + 4 and off-diagonals -1/h²
  • Linear system solver: Direct O(N) Thomas algorithm (TDMA) utilizing strict diagonal dominance

4. Theory and graph choice

In engineering and physics, equilibrium states—such as temperature distributions along a conducting cooling fin, electrostatic potentials between capacitor plates, or the bending deflections of a loaded structural beam—are governed by Boundary Value Problems (BVPs). Unlike initial value problems where the state evolves forward from a single initial instant, BVPs enforce constraints at two or more distant spatial boundaries simultaneously. The finite difference method discretizes the continuous spatial domain into a discrete grid of nodes, replacing continuous differential operators with localized central difference algebraic stencils. The resulting matrix system is sparse, banded, and tridiagonal, enabling direct solution in linear O(N) time via the Thomas algorithm. In this laboratory, we formulate the central difference equations for a two-point BVP, examine tridiagonal diagonal dominance, and verify the second-order O(h²) global error convergence rate.

ln(E_max) = α · ln(h) + ln(C)

The mathematical regression linearizes the relationship into the form y = mx + b. Here, the independent variable x represents Logarithmic Mesh Spacing ln(h), and the dependent variable y represents Logarithmic Maximum Error ln(E_max). The slope m directly extracts BVP Central Difference Order (α), while the intercept b accounts for residual baseline offsets.

5. Method

  1. Set up -y'' + 4y = 16x on [0, 1] with boundary conditions y(0) = 0 and y(1) = 4, verifying the analytic solution y(x) = 4x.
  2. For refinement levels k = 1 to 6, set grid intervals N = 5 · 2^{k-1} with spacing h = 1.0 / N.
  3. Set interior matrix rows: -y_{i-1}/h² + (2/h² + 4) y_i - y_{i+1}/h² = 16 x_i for i = 1, ..., N-1.
  4. Substitute known boundary values y_0 = 0 and y_N = 4 into the first and last equations, transferring knowns to vector b.
  5. Execute TDMA forward sweep and back substitution to obtain nodal vector y, computing maximum error E_max = ||y - y_exact||_∞.
  6. Plot ln(E_max) versus ln(h) and compute the linear regression slope to verify α = 2.000 with R² = 1.000000.

11. Precautions and limitations

  • Verify that the tridiagonal matrix is strictly diagonally dominant before invoking the Thomas algorithm to ensure numerical stability without pivoting.
  • Incorporate Dirichlet boundary conditions by modifying the right-hand vector b rather than augmenting the matrix with trivial identity rows.
  • When discretizing Neumann boundary conditions, always use central difference ghost points to avoid degrading global accuracy to first order.
  • Ensure floating point precision remains 64-bit IEEE 754 to prevent roundoff error when 1/h² becomes large on fine meshes.
  • Check for singular matrices when solving Helmholtz equations -y'' - k² y = f where k² matches an eigenvalue of the Laplacian.
  • Never use uniform central differences for advection-dominated problems where the grid Péclet number Pe > 1; employ upwinding.

Finite difference methods are naturally suited for simple rectangular or tensor-product geometries; complex curved boundaries require finite elements or coordinate mappings.
