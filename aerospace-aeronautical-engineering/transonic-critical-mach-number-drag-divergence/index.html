FOLLOW THE METHOD

A reason behind every step.

Detect critical Mach number M_crit where local sonic flow is first reached and measure the drag divergence Mach number M_dd and cubic wave drag rise. Standardized parameter settings: 0.0005, 0.001, 0.002, 0.0035, 0.0055, 0.008 dimensionless.

01

Slotted Wall Plenum Preparation

Set slotted wall ventilation porosity to 6% and verify plenum chamber auxiliary suction pump operation.

02

Subcritical Baseline Calibration

Run tunnel at M_inf = 0.65 (well below M_crit), recording baseline subcritical parasite and induced drag C_D,subcrit.

03

Critical Mach Identification

Gradually increase Mach number until surface pressure taps record local sonic speed (C_p = C_p,crit), logging M_crit = 0.720.

04

Transonic Mach Stepping

Step free-stream Mach through values corresponding to (M_inf - M_crit)^3 = 0.0005, 0.0010, 0.0020, 0.0035, 0.0055, and 0.0080.

05

Wave Drag Isolation

Measure total drag C_D at each Mach number and subtract baseline subcritical drag to isolate wave drag Delta C_D,wave = C_D - C_D,subcrit.

06

Wave Drag Cubic Regression

Plot Delta C_D,wave versus (M_inf - M_crit)^3, perform linear regression to determine scaling constant k_w, and pinpoint drag divergence M_dd.
