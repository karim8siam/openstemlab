FOLLOW THE METHOD

A reason behind every step.

Measure differential gain and common-mode gain of a classic three-op-amp biomedical instrumentation amplifier to calculate CMRR across common-mode interference voltages. Standardized parameter settings: 0.5, 1.0, 1.5, 2.0, 2.5, 3.0 V.

01

Differential Gain Verification

Apply a 1.000 mV peak-to-peak 10 Hz pure differential input signal; verify that differential output reads exactly 1.000 V peak-to-peak, confirming A_d = 1000 V/V.

02

Common-Mode Test Configuration

Tie both differential non-inverting and inverting inputs together to apply identical common-mode voltage V_cm simultaneously.

03

Initial Common-Mode Excitation

Apply a 60 Hz sinusoidal common-mode voltage of 0.500 V RMS, monitoring amplifier rails to ensure linear range.

04

Microvolt Output Leakage Measurement

Measure the residual 60 Hz output voltage V_out,cm using the precision true-RMS microvoltmeter over a 30-second integration window.

05

Common-Mode Progression Sequence

Increment common-mode voltage V_cm through 1.0, 1.5, 2.0, 2.5, and 3.0 V RMS, recording V_out,cm at each stage.

06

Gain Regression and CMRR Computation

Plot V_out,cm against V_cm to determine common-mode gain A_cm = slope / 1000 (in V/V), then calculate CMRR = 20·log10(A_d / A_cm).
