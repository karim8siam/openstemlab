Algorithmic assumptions and limits

The simulated execution model evaluates complete balanced binary search trees where height scales deterministically as h(n) = ⌊log₂ n⌋ + 1 levels. In physical computer systems, tree performance is modulated by dynamic memory allocator fragmentation, non-contiguous heap pointer chasing across CPU cache lines, TLB virtual memory translation misses for large datasets, and non-deterministic tree shapes resulting from arbitrary insertion and deletion sequences. The simulated benchmark environment reflects an idealized complete balanced binary search tree where n distinct keys are distributed with optimal structural symmetry. For any key count n, the maximum tree height is deterministically governed by the floor logarithm h(n) = ⌊log₂ n⌋ + 1 levels. Across the designated power-of-two benchmark samples n in [64, 128, 256, 512, 1024, 2048, 4096], the logarithmic entropy x = log₂(n) scales through exact integer values [6, 7, 8, 9, 10, 11, 12] bits, yielding tree heights h in [7, 8, 9, 10, 11, 12, 13] levels. Consequently, the empirical relationship satisfies the exact linear model h = 1.0000 · log₂(n) + 1.0000 levels, providing an ideal microarchitectural testbed for Ordinary Least-Squares regression with zero residual error.

FOLLOW THE METHOD

A reason behind every step.

Determine the tree height scaling factor α and examine search path depth across balanced and degenerate binary search trees, verifying the logarithmic bound h = Θ(log₂ n) and analyzing AVL rotation mechanics. Suggested independent settings: 64, 128, 256, 512, 1024, 2048, 4096 keys.

01

Initialize Tree Topology & Telemetry Registers

Configure the virtual laboratory environment with 64-bit pointer alignment and verify that the root pointer is initialized to NULL with a baseline tree height of 0 levels.

02

Select Target Key Count

Adjust the independent variable control slider to choose a dataset size n between 64 and 4,096 keys across the designated power-of-two benchmark settings.

03

Execute Balanced Binary Tree Construction

Trigger the benchmark engine to insert n unique keys into the binary search tree using optimal balanced insertion, maintaining the structural invariant across all subtrees.

04

Measure Maximum Tree Height & Record Observation

Read the deterministic root-to-leaf height h from the height register, verify that h matches ⌊log₂ n⌋ + 1 levels, and record the observation into the experimental notebook.

05

Repeat Across Full Scale Range

Systematically iterate through all 7 power-of-two key counts (n = 64, 128, 256, 512, 1024, 2048, and 4096 keys), recording the exact tree height for each dataset scale.

06

Perform OLS Regression & Degeneracy Analysis

Plot measured tree height h against logarithmic key entropy x = log₂(n), perform Ordinary Least-Squares regression to compute the height scaling factor α, and compare with degenerate unbalance.
