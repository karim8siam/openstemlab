Numerical assumptions and limits

Standard Gauss-Legendre nodes are non-nested: doubling n requires discarding all previous function evaluations unless Gauss-Kronrod extensions are used. The simulation evaluates composite 3-point Gauss-Legendre quadrature for step sizes h = 0.20 / 2^{k-1}. The logarithmic regression ln(E) = α·ln(h) + ln(C) extracts the asymptotic order α = 6.000 with R² = 1.000000.

Calculate Canonical 3-Point Nodes and Weights

Set reference nodes ξ = {-√(3/5), 0, √(3/5)} and weights w = {5/9, 8/9, 5/9} on [-1, 1].

Verify Degree 5 Algebraic Precision

Integrate test monomials x⁰, x¹, x², x³, x⁴, x⁵ and verify zero residual error to double machine precision.

03

Partition Domain into N Sub-Panels

Subdivide [0, 1] into N = 2^{k-1} sub-panels with panel width h = 1.0 / N across refinement levels k = 1 to 6.

04

Apply Affine Map & Accumulate Integral

Map nodes to each sub-panel [a_i, b_i] and accumulate G_3(h) = ∑_{i=1}^N (h/2) ∑_{j=1}^3 w_j f(a_i + (h/2)(1 + ξ_j)).

05

Evaluate Absolute Quadrature Error

Compare G_3(h) against the exact analytic integral and verify error reduction by 2⁶ = 64 per mesh halving.

06

Fit Logarithmic Convergence Slope

Plot ln(E_h) versus ln(h) and compute the linear regression slope to verify α = 6.000.
