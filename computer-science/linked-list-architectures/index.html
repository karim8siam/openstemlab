Algorithmic assumptions and limits

The simulated execution model evaluates idealized heap memory allocation for a 64-bit doubly linked list with 32-byte node alignment and 64-byte sentinel overhead. In physical computer systems, dynamic heap memory is subjected to internal allocator fragmentation, chunk metadata overhead (typically 8-16 bytes per malloc block), virtual memory page fragmentation across 4096-byte boundaries, and non-deterministic cache miss latency depending on heap heap address randomization. The simulated benchmark environment models a high-performance 64-bit circular Doubly Linked List with Sentinel nodes. Under standard 64-bit POSIX/AMD64 heap allocators, each doubly linked node allocates 32 bytes (8 bytes 64-bit data payload, 8 bytes forward pointer next, 8 bytes backward pointer prev, and 8 bytes malloc alignment/padding). The dual dummy sentinel nodes (head and tail) establish an invariant 64-byte baseline allocation (M_0 = 64.0000 bytes). Transmitting or allocating n nodes yields the exact linear relationship M(n) = 32.0000 · n + 64.0000 bytes, establishing an optimal empirical framework for Ordinary Least-Squares regression.
