FOLLOW THE METHOD

A reason behind every step.

Measure blade surface pressure distributions, exit flow turning angles theta_t, and Lieblein diffusion factor D across compressor blade cascades to determine stall margin. Standardized parameter settings: 12.0, 16.0, 20.0, 25.0, 30.0, 35.0 deg.

01

Cascade Installation and Periodic Alignment

Install the 7-blade cascade, verifying uniform blade spacing s = 80 mm and adjusting inlet sidewall bleeds for pitchwise flow periodicity.

02

Wind Tunnel Speed Stabilization

Run tunnel to test inlet velocity V_1 = 50 m/s, stabilizing inlet dynamic pressure at q_1 = 1530 Pa.

03

Inlet Flow Angle Calibration

Adjust inlet guide vanes to set initial flow turning angle to theta_t = 12.0 degrees, measuring blade surface C_p distributions.

04

Systematic Turning Angle Stepping

Step the turning angle through theta_t = 16.0, 20.0, 25.0, 30.0, and 35.0 degrees, recording surface pressures and exit wake profiles.

05

Diffusion Factor Computation

Calculate velocity ratio V_2 / V_1 and tangential velocity turning Delta V_theta to compute Lieblein diffusion factor D.

06

Diffusion Factor Linear Regression

Plot D versus theta_t, perform linear regression to determine turning sensitivity dD / dtheta_t, and pinpoint the stall limit D_crit = 0.58.
