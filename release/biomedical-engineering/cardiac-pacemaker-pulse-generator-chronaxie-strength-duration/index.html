Biomedical assumptions and boundary condition limits

The Lapicque-Weiss model assumes a simple parallel R-C membrane circuit, neglecting active voltage-gated sodium channel reactivation dynamics. Evaluated on a Medtronic clinical cardiac pulse generator interfaced with a steroid-eluting active-fixation bipolar endocardial pacing lead (tip area 1.2 mm², pacing impedance R = 550 Ω) immersed in 37.0 °C physiological saline. Rheobase voltage V_rh = 0.6500 V, chronaxie time t_ch = 0.4923 ms, yielding Lapicque slope m_ch = 0.3200 V·ms across pulse widths t_p from 0.20 to 1.00 ms (1/t_p from 5.0 to 1.0 ms⁻¹).

FOLLOW THE METHOD

A reason behind every step.

Determine the chronaxie time t_ch and rheobase voltage V_rh of an implantable cardiac pacemaker lead-tissue interface across pulse widths using the Lapicque-Weiss model. Standardized parameter settings: 0.2, 0.25, 0.3333, 0.5, 0.6667, 1.0 ms.

01

Pacing Lead Bath Mounting and Impedance Verification

Submerge bipolar pacing lead tip in 37.0 °C saline, connect to pacing simulator, and verify pacing impedance R = 550 ± 20 Ω via telemetry.

02

Telemetry Programmer Interrogation

Position wireless programming wand over pacemaker, establish bidirectional telemetry link, and select automated capture threshold testing mode.

03

Initial Pulse Width Configuration

Program pacemaker pulse duration to t_p = 0.20 ms (inverse width 1/t_p = 5.00 ms⁻¹).

04

Capture Threshold Voltage Search

Step pacing voltage downward from 3.0 V in 0.05 V increments until evoked electrical response ceases, recording last successful capture voltage as V_th.

05

Pulse Width Progression Sequence

Increment pulse width through 0.25 ms (1/t_p = 4.00), 0.333 ms (3.00), 0.50 ms (2.00), 0.667 ms (1.50), and 1.00 ms (1.00 ms⁻¹), measuring capture threshold V_th at each setting.

06

Lapicque-Weiss Linear Regression Analysis

Plot threshold voltage V_th versus inverse pulse width 1/t_p, extract slope m_ch and y-intercept V_rh, and calculate chronaxie time t_ch = m_ch / V_rh.
