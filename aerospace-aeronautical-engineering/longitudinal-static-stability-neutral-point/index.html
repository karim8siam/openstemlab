Aeronautical assumptions and boundary condition limits

Linear stability derivative dC_m/dC_L assumes attached flow and constant wing downwash gradient depsilon/dalpha. Linear regression of dC_m/dC_L against x_cg/c yields a slope of 1.0000 and intercept b = -0.3600, locating the neutral point at x_np/c = 0.3600 with R^2 > 0.999999.

FOLLOW THE METHOD

A reason behind every step.

Measure aircraft pitching moment slope dC_m / dC_L across center-of-gravity locations x_cg to determine the stick-fixed neutral point x_np and static margin. Standardized parameter settings: 0.2, 0.23, 0.26, 0.29, 0.32, 0.35 dimensionless.

01

Model Internal Balance Alignment

Install the complete aircraft model onto the wind tunnel sting balance, zeroing pitching moments at zero aerodynamic load.

02

Initial CG Ballast Setting

Position the internal ballast slider to place center of gravity at the forward limit x_cg / c = 0.20.

03

Wind Tunnel Flow Initialization

Run the wind tunnel to V_inf = 35 m/s, stabilizing dynamic pressure at q_inf = 750 Pa.

04

Pitch Sweep and Moment Slope Extraction

Sweep model incidence through alpha = -2, 0, 2, 4, and 6 degrees, measuring C_m and C_L to extract slope dC_m / dC_L.

05

Systematic Aft CG Translation

Step the internal ballast aft through x_cg / c = 0.23, 0.26, 0.29, 0.32, and 0.35, repeating the pitch sweep at each station.

06

Neutral Point Linear Regression

Plot dC_m / dC_L versus x_cg / c, perform linear regression to verify unity slope m = 1.000, and find horizontal intercept where dC_m/dC_L = 0 to identify x_np / c.
