Algorithmic assumptions and limits

The simulated execution environment models idealized scalar CPU memory pointer dereferences where each node transition executes with deterministic cost of 1 operation (T(L) = L + 1). In physical semiconductor microprocessors, wall-clock retrieval latency is modulated by CPU L1/L2 data cache hit ratios during pointer chasing across dynamic heap nodes, Translation Lookaside Buffer (TLB) virtual memory page walks, hardware prefetcher limitations on branching structures, and memory bus bandwidth contention. In the Trie key retrieval benchmark across search key lengths L in [4, 48] characters, the retrieval algorithm starts at the root sentinel node (consuming 1 initial pointer inspection) and sequentially dereferences exactly one child pointer for each character in the query key. Because each character transition advances down the trie hierarchy by exactly 1 level, total memory pointer dereferences scale deterministically as T(L) = 1.0000 · L + 1.0000 dereferences with exact theoretical intercept T_0 = 1.0000 dereference. Ordinary least-squares regression across all benchmark trials yields an ideal coefficient of determination R² = 1.000000 with zero residual variance.

Computational tools & environment.

Multi-Way Trie Node Memory Allocator

Allocates 64-bit hierarchical trie nodes equipped with fixed character pointer arrays, terminal payload flags, and prefix occupancy counters.

Compressed Radix Tree (Patricia Trie) Path Compressor

Dynamically condenses non-branching single-child edge chains into composite string edges, bounding total nodes to at most 2n - 1.

Ternary Search Tree (TST) Three-Way Splitter

Constructs balanced three-way branching nodes (left < c, equal == c, right > c), combining binary tree memory efficiency with prefix retrieval speed.

Longest Prefix Match (LPM) IP Routing Table Engine

Simulates CIDR IPv4/IPv6 destination address routing, traversing binary trie branch trees to extract the most specific subnet mask in O(W) time.

Aho-Corasick Multi-String Trie Automaton Matcher

Synthetic Lexicon & Query Stream Generator

Initialize Multi-Way Trie Root & Alphabet Pointer Array

Allocate the trie root node, clearing all 64 child pointer entries to NULL and initializing the root sentinel dereference baseline T_0 = 1 operation.

Select Prefix Query Key Length L

Adjust the independent variable control slider to choose a search key length L between 4 and 64 characters across the designated benchmark sample points.

Synthesize Dictionary & Prefix Query Key

Trigger the synthetic generator to load a 10,000-key dictionary into the trie and synthesize a deterministic target query string of length L.

04

Execute Trie Search Path Traversal

Traverse the trie from root to leaf, resolving characters sequentially from index 0 to L-1. For each character, dereference the corresponding child pointer.

05

Capture Cumulative Node Pointer Dereferences

Read the total pointer dereference count T(L) from the memory access monitor upon locating the terminal node, verifying that T(L) = L + 1 dereferences.

06

Perform Linear Asymptotic Regression & Structural Profiling

Record total dereferences across all seven benchmark trials. Regress T(L) against key length L to compute slope k_trie, intercept T_0, and coefficient of determination R².
