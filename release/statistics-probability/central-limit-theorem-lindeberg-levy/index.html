Statistical assumptions and distribution limits

The classical CLT applies only to sums of variables with finite second moments; it fails for heavy-tailed distributions like Cauchy or Pareto (α ≤ 2). The empirical regression of ln(SE) versus ln(N) yields an empirical slope of m = -0.5000, confirming the theoretical CLT root-N rate with R² = 1.000000.

FOLLOW THE METHOD

A reason behind every step.

Demonstrate the asymptotic normality of standardized sample sums from non-Gaussian parent distributions, verify the Berry-Esseen theorem error bounds, and quantify standard error scaling SE = σ / √N. Standardized parameter settings: 10.0, 20.0, 40.0, 80.0, 160.0, 320.0 samples.

01

Configure Non-Gaussian Parent Distribution

Select the continuous uniform distribution U[0, 1] with known mean μ = 0.5 and variance σ² = 1/12 ≈ 0.08333 (σ = 0.28868).

02

Simulate Standardized Sample Averages for N = 10

Set sample size N = 10. Draw 5,000 independent samples of size N, evaluate the sample mean X̄ for each, and compute standardized scores Z = (X̄ - μ) / (σ / √N).

03

Measure Empirical Standard Error

Calculate the standard deviation of the 5,000 sample means to obtain the empirical standard error SE = σ / √N. For N = 10, SE = 0.28868 / √10 = 0.09129.

04

Evaluate Berry-Esseen Normality Convergence

Measure the Kolmogorov distance between the empirical distribution of Z and the Gaussian CDF Φ(z), verifying that the deviation satisfies the Berry-Esseen bound.

05

Step Sample Size Across N = 10 to 320

Increment sample size across N ∈ {10, 20, 40, 80, 160, 320}, observing rapid convergence of the sampling distribution to the bell-shaped Gaussian curve.

06

Execute Log-Log Regression on Standard Error

Fit a linear regression model to the coordinates (x = ln(N), y = ln(SE)). Confirm that the empirical gradient m = -0.5000 rigorously verifies the 1/√N standard error scaling.
